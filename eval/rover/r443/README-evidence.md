## 1. 结论（三条）

1. **本地 r1 成本真值化成功，且 R442 的字符/2 折算低估 61%** ⇒ 含本地口径的降幅比 R442 报告更差：
   M20 中簇 `D_remote` = **46.18%** → `D_remote+local`(R442 式) = **33.25%**（复现 R442 的 33.26）→ **真值口径 = 25.32%**
   ⇒ **「≥30%」在含本地 r1 真值口径下不成立**（M20 也不成立）。口径绑定是必须的，不是修辞。
2. **「被跳轮不回放」的单变量实测效应 = 6540 tok**（BRJ 32968 → BRJRP 39508），比 R442 的**离线代数分解**
   （4830.5）高 **35.4%** ⇒ 离线分解低估 26%，机制收益比 R442 记录更大；R442「实测偏保守」的方向被证实、幅度被修正。
3. **门相关记账恒等成立**（`tokens_evaluated == prompt_new + cache_n`）：门 17/17、判官 13/13，**0 违规**；
   反事实开关可机检（`replay_skipped` 0→1、`dropped_sum` 2024→0）；ρ（micro_step）token 恒 0 ⇒ 对判据零影响。

1. 真值只覆盖 **M20 一列**（短档 V2b、单跳档 W8/W20 仍只有折算口径）⇒ 矩阵其余列待补测。
