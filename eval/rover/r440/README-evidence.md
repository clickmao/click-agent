# R440 证据 · 一轮任务降幅的**分档实测**（长度梯 V1/V2/V2b/V4/V5 + 位置单变量 + 无设备负控）

口径: 降幅 = 1 − Σ远端(B 臂) / Σ远端(A 臂); 单位 = **一轮任务**（非一次链调用, R437 口径澄清令）。
被测二进制: `/tmp/pub_r438/agenthost`（AOT native, 15,188,768 B, sha256 `6167e9da…`, V0 形态闸 PASS, IL 警告 0）— 本轮**零源码改动**, 无重发布义务。
桩 = 外部真值（逐请求落盘 token, `eval/rover/r430` 器具 + `eval/rover/r439/channel_marks.py`）; 本地设备 = r1-distill-1.5b-q4km（门+关系判官共用, `-np 1 -c 4608`）。

## 1. 因果链
R437 只给了**模型外推**的分档降幅（回验仅 p8/p12 两格） ⇒ 用户口径「一轮任务可能多次链调用」尚未有**实测**支撑 ⇒ 本轮把分档梯做成可跑网格:
单次(N=1) / 短(N=3,4) / 长(N=20) × 可跳轮位置（散布 vs 晚簇）× 有无本地设备（负控）。
关键对照: **V4（N=20, 可跳 7/20 全在 t14–t20）vs V20（R439, N=20, 可跳 7/20 散布）** = 同长度、同文本集、同认可轮数 ⇒ 单变量 = 位置。

## 4. 判据机判（`compare_r440.py` ⇒ `compare-r440.json`）
- **C1 门质量 PASS**: 全网格 BRJ `fn=0 ∧ fp=0 ∧ acc=1.0`；V5 为强检验（19 条真诉求含 7 条未经 r1 实测文本）⇒ **新增文本零误杀**。
- **C2 分母复现 FAIL（严格式）**: 预注册写「同位置逐位同值」被证伪 — V4 vs V20 16 轮可比中 4 轮逐位同值、最差 t13 差 **208 tok**（5.6%）；V1 vs p8-A 差 3 tok。**总量级**偏差 V4 vs V20 = **+0.12%**（事后收窄口径 PASS）。
- **C3 ±3pt FAIL（3/5 格）**: V1 ✓ / V5 ✓ / V2、V2b、V4 ✗ —— 逐条根因**都在预测器**（见 §5），不在被测机理。
- **C4 零可跳必为负 PASS**（V1 −3.95%、V5 −2.40%）。
- **C5 BP 负控 PASS**（−5.47%、skip=0、远端判官回退 13 次 ⇒ 增益须来自真实本地设备）。
- **C6 质量不退化 PASS**（全臂 acc=1.0, unassigned_calls=0, 回复原文落盘）。
- **C7 位置单变量 FAIL**（见上）。

## 5. 事后校核（**看到实测后才成立**，与预注册分列）
- **H1 成本律（常数律）**: 逐调用角色块开销 δ = B(i) − A(i) ≡ **77 tok**, 在 **5/5 网格**逐轮完全一致（V1/V2/V2b/V4/V5）。预注册模型假设 δ(i) = 75.2 + 1.8·i（由 p12 拟合外推）⇒ 在 i=20 处高估 35 tok/调用。
- **H2 重锚模型 5/5 ≤0.47 pt**: 用「同网格 A 臂实测分母 + δ=77 常数」重算: V1 0.00 / V2 0.00 / V2b 0.00 / V4 **+0.47** / V5 0.00 pt。
- **H3 预注册缺陷定位**: ① A 分母跨网格「逐记录下标」代理（V20 A 臂 25 调用/20 轮 ⇒ 位移）使 V4 预注册 A=66951 vs 实测 61281（**+9.25%**）；② V2b 的 A 分母**漏计被跳轮在 A 臂的成本** ⇒ 预测出 −3.85% 而实测 +32.24%；③ δ 线性外推（见 H1）。
- **二阶项（块回放移除）**: V20 的 B 比「δ=77 常数律」再低 2227 tok = 被跳轮的**从未发出内联块**不再被后续调用回放（R438 修复的机制）⇒ 该项在**晚簇**网格（V4）≈0（跳轮后无后续调用），在**散布**网格显著。两项合起来解释 5/5 网格。

## 6. 诚实边界
1. 远端 token 为**桩侧估算**（字符/2 口径），非 provider 计费/缓存命中；本判据只对「同一网格 A vs B」的相对降幅有效。
2. 本地设备成本（r1 门+判官 ~25–47 s/轮串行）**不计入 API token** 但非零；本轮未测墙钟/CPU 口径。
3. V2 设计失效（目标轮被吞并 ⇒ realized S=∅）⇒ 该格**未测到**目标变量, 不得读成「短任务无收益」；V2b 是补格（可跳 1/4 ⇒ +32.24%）。
4. V20 的逐轮 B−A 均值（−343 tok）是**多调用轮的归属假象** ⇒ V20 不参与 H1/H2（H2 只报 5 网格）。
5. C2/C3/C7 的失败是**预测器缺陷**（分母代理 + 成本律外推），非机理失败；但按纪律仍记 **FAIL**，修后模型只能记 `checks_posthoc`。
6. 单机单次；未做同臂复跑（确定性留给下轮候选）。
7. 桩返回固定话术 ⇒ 回复内容无语义，`acc` 只检验门的跳过/放行判决与设计标签一致。
