## 读数 1 — 口径三档（同一批档案, 只换加项）

| 网格 | N | 可跳 k/N | ① D_remote | ② D_content-sym | ③ D_local-incl | ④ D_strict（最严） | 转正闭式下界 `k/N >` |

- ① = R436–R441 沿用口径（只算远端主生成 prompt+completion）；③ = 再加本地 r1（门提示字符 + 门生成字符 + 本地判官 token，按 **字符/2** 折算）；② = ① 去掉**块内容不对称**后；④ = ②+③。
- **口径钉死结论**: 「≥30%」只在 **① 远端 API token 口径**下是普适描述；**含本地 r1 后**仅中簇 7/20 仍达标（33.26%，最严 32.09%），W8/W20 单跳格**转为净亏**（−2.06% / −10.92%）。⇒ KPI 必须携带口径标签，缺标签的 ≥30% 是**空心宣称**。
- **转正闭式（3/3 命中）**: 含本地口径转正 ⟺ `k/N > c_local_per_turn / s_per_skip`，实测 `c_local_per_turn` = 341.4 / 383.4 / 395.6 tok，`s_per_skip` = 2376 / 1736 / 4040 tok。观测逐格一致：12.5%<14.37% 亏、5%<22.09% 亏、35%>9.79% 盈。
- 本地成本结构: 门在**每个非机械轮**都跑（不只跳轮）⇒ 本地成本 ≈ 常数 × N（≈390 tok/轮），与跳轮数无关 ⇒ 低占比格必亏。
