**产物**: 工作区相对路径 `games/wythoff.py` (7318 bytes), `ls -l` 已确认真实存在。

**接口**: `solve(text) -> "LOSE" | "WIN"` (LOSE = 必败点/先手必败)。
**输入**: 首行两整数 a b, 顺序任意; 负值按 0; 多 token 忽略、缺则补 0、非法 token 跳过; 空输入 → `LOSE` (即 (0,0))。

**算法 (修正后)**: 排序取 `d = b - a`, 必败 ⟺ `a == floor(d*phi)`, 用**纯整数精确式** `floor(n*phi) = (n + isqrt(5n²)) // 2` —— 首版用浮点 `math.floor(PHI*d)` 在 d≈13 处产生下偏误差 (算出 12 而非 13), 导致 8/13、9/15 等真必败点被判 WIN。改整数式后浮点误判消失。

**验证证据 (真实运行, stdout/stderr 分离)**:
- 自检 stdout 只打印 `PASS`, 退出码 0 (stderr 为空, 无 FAIL 行)。
- 手动样例: `2 1`→LOSE, `1 2`→LOSE, `3 5`→LOSE。

自检 8 组: 12 项 Beatty 必败点+交换对称 / 8 项必胜点 / **与独立暴力 DP 逐点对账 0..40 共 1681 局面** (第三只眼) / 结构不变式 (差分 d∈1..79 逐一唯一覆盖) / floor_phi_times 对 0..1999 与高精度浮点对照 / 边界 10 例 / 负向控制 / 大数自洽 (n 至 10^12, 含 (a+1, a+n) 必为 WIN 的反面样本), 耗时 <5s。
