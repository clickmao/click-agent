## 6. 诚实边界

- **没测到**: 本轮的降幅全部是「远端 LLM API token 数（桩应答固定 7 tok/次）」口径；**未测**真实 API 计费、未测用户侧感知延迟、未测 r1 判官自身的本地算力/功耗代价（r1 判官轮耗时 24–40s 已落 `run_*.log`，但未做端到端时延 KPI）。
- **口径**: 「用户一轮任务总数 tokens」= 该轮全部远端 G 调用 (prompt+completion) 之和；本地 r1 调用不计入（与 R436–R440 同口径）。若把本地 r1 token 也计入总量，降幅会显著变负 —— 这是下一轮必须钉的口径分歧点。
- **两臂不对称（新发现，已入 debt）**: BRJ 臂内联块携带累积 [已完成] 列表，A 臂同位置块是 [Memory (RAG)]/[联想] 行 ⇒ 两臂块**不同源**，使实测降幅偏**保守**（W20: 模型预测 5.74% vs 实测 3.20%，差额 2.55pt 主要来自 B 臂 t≥14 的块膨胀）。
- **ρ 无确定触发条件**: 同二进制同网格下，跳轮微步骤远端调用 0（W8/M20/V2b）或 41 tok（W20）两种都出现了 ⇒ 未定位触发条件。
- **C2/C3 未通过**（2/8），不得对外宣称「预注册判据全绿」。
