## 1. 独立 oracle（与被测零共享代码）

来源 = 冻结题面**逐字规格**（非期望输出）：合法着法三族（取一堆 / 两堆同取），必胜 ⇒ 输出**字典序最小**的必胜着法 `WIN i j`，否则 `LOSE`。
实现路线与被测/生成器可能用的「冷点公式 / Beatty 序列」**不同**：按 `a+b` 升序的定义式 DP 求 P 位 + 枚举三族着法取字典序最小。
**正控 J0**：oracle 在 15 例上复现冻结期望字节 **15/15**（不一致 0）。

## 3. 机制归因（**行为式谓词**，问产物自己的接口）

对每个非 OK 实例，用产物**自己**的判定/着法接口回问「它认为着法落点是不是必败位 / 它自己选的是什么」，只把与「产物自身冷点谓词」一致的失败归到该谓词（承技能「机制归因」节）：

| 机制桶 | 例次 | 占比 |
|---|---|---|
| `COLD_PRED_WRONG`（判定层：谓词与 oracle 对同一落点判断相反） | **113** | **71.1%** |
| `CRASH`（谓词全否 ⇒ `best=None` ⇒ 交付前未自验） | 31 | 19.5% |
| `ILLEGAL_MOVE`（选点层：着法本身越界/不合法） | 9 | 5.7% |
| `UNCLASSIFIED` | 4 | 2.5% |
| `ENUM_ORDER`（枚举序层：仅字典序子型） | 2 | 1.3% |

- **J4（主判据）**：`COLD_PRED_WRONG` = 71.1% ≥ 50% ⇒ **成立**。
- **判定层族合计 = (113+31)/159 = 90.6%**（两桶**分列**，不合并成一个数）。
- **CRASH 与判定层同源、有代码级证据**（`aux_r622.py` 在产物树副本上复现）：`python3 -B -m games wythoff` + 输入 `21 25` ⇒ `rc=1 / stdout 空 / TypeError: cannot unpack non-iterable NoneType` @ `games/wythoff.py:48` `i, j = best`。⇒ 「谓词全否 ⇒ 无必胜着法 ⇒ 空值直出 ⇒ 未自验即交付」。
- 与 R600 登记的「主桶 = 冷集构造层」（`src/agent/r1/ArtifactCarryover.cs:11`）**不冲突但不沿用**：本轮独立定因把它量化到 **判定层占 90.6%**，并**新增**「同源硬崩」这一桶；「选点/枚举序」仅 6.9%。
- **T 与 C 之差**：判定层桶在两臂同向（+65 例次 / +24pt）⇒ 回退面收益方向一致，但**尚未追平真值**（0.826 vs 1.000）。
