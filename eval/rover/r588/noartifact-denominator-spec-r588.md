## 2. 定因（候选③，与⑤同一份证据）

`
  reply(18,913 B) 的契约块  →  结构**不闭合**（字符串感知括号扫描无法归零：balanced=false）
  →  严格 JSON 解析在读至 **byte 6455** 的 `{` 处落「期望属性名」
  →  产品报 `BytePositionInLine: 6455`（**逐字节对齐，delta = 0**；两侧独立解析器同一文本同一位置）
  →  `stage=contract` / `rc=4`（谓词落点 `src/agent/r1/R1Pipeline.cs:147`：契约未过 (errors=1)）
  →  `steps_executed=0` / `plan_steps_total=0`  ⇒  执行体零步  ⇒  工作区零文件  ⇒  该窗 0/58
`

⇒ 该类**不是**「产物写盘/持久化缺陷」，也**不是**独立的「计划未落盘」谓词；是**上游契约块结构缺陷**
（模型把含多行文本的命令塞进 JSON 字符串时产出不可解析的块）在**契约阶段**被拒收的下游后果。

两侧成对控制：正控 = 同批 `rc=0` 跑次（`r585/w154/agentD-r1`）契约块 `balanced=true` 且解析 OK；
负控 = 同一块删一个 `}` ⇒ 解析 FAIL。⇒ 提取/判定器具非恒红也非恒绿（`has_teeth=true`）。

**诚实边界**：精确到**字符**的病因未定因（该块内引号成对、无控制字符；个别计划元素单独解析亦失败），
指向「JSON 转义序列与解析器口径不一致」的候选，不作结论、不入判据。
