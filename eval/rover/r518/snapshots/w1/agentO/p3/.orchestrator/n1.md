**实现**
- 文件形态：`{"version":1,"next_id":<int>,"tasks":{"<id>":{id,text,done,created_at,expires_at}}}` —— 合法 JSON 对象，`next_id` 整数持久化。
- `load_store`：不存在→空状态；BOM/空/非 UTF-8/非 JSON/顶层非对象/缺或非整数 `next_id`/`next_id<=max_id`/task 缺字段或类型不符 → `StoreError`（供 cli 映射退出码 4）。
- `save_store`：`tempfile.mkstemp(dir=同目录)` + `write/flush/fsync` + `os.replace` 原子重命名，目录 fsync；异常路径 finally 清理临时文件；`validate_state` 强制 `next_id>max(id)`（只增不减不变式）。输出 UTF-8 无 BOM。

**自测**：`python3 -B -m tasksvc.store --selftest` → rc=0，18/18 PASS（含文本逐字节往返、空文件回落、临时文件零残留、5 类损坏负向控制）。
