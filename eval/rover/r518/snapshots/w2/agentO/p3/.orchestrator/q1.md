**实现要点**（只覆盖本段两条职责）
- `Store(wal_path, now_fn)`：内存态 `dict[key] = (value, expires_at)`；写操作在 `_lock` 内完成「改内存 → 追加 WAL」同一临界区，避免丢更新。
- WAL 追加：每行一个 JSON 对象（`ensure_ascii=False`），必含 `op`（仅 `put`/`delete`/`incr`）与 `key`，另带 `value`/`expires_at`/`by`/`ts` 供重放；UTF-8 无 BOM、`\n` 分帧、逐行 `flush`+`os.fsync`。
- 重放 `replay()`：逐行 `json.loads`；`put` 覆盖、`incr` 累加（缺失按 0 起算）、`delete` 删除；重放末尾按当前时钟剔除已过期键，**不得复活**；坏行（半截尾行）跳过并计数，不崩溃。
- 惰性过期：读取时 `now >= expires_at` 视为不存在，并计入 `expired` 累计。
- 只依赖标准库 `json/os/threading/time`。
