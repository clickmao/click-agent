## 3. 外部效度裁决（本轮最重要的读数）

- 机械门不变量：`¬Ack ⇒ Pass（不问 r1）`；`Skip ⇒ Ack`（源码 `IndustrialAgentV2.cs:1496` 前置门 + `:1519` 后置 fail-closed）。
- 真实流量：**ack = 0 / 1542（0.0%）**，独立复算「纯认可族消息」亦为 **0**。来源侧 Ack 族字面量
  `好嗯行明白了知道谢收到多辛苦可以先就的` 由源码正则派生（非手抄）。
- 合成网格 M20：同规则 ⇒ **7/20 = 35.0%** 可跳。
- ⇒ **两个后果**：
  1. **本地侧（真实收益）**：真实流量上每轮都命中 `¬Ack ⇒ Pass` ⇒ 门 r1 调用 **0** 次，省掉「必然 Pass 的浪费调用」（源码自述 ≈638.8 tok/轮）。这一项在真实流量上**满额成立**。
  2. **远端侧（KPI 主目标）**：远端可跳需 `Ack` 成立 ⇒ 真实流量 `Skip = 0` ⇒
     **「不必要远端 LLM API 请求下降 ≥30%」在真实流量上的实现额 = 0**。
     已登记的 33.32% 降幅来自 M20 构造的 7/20 认可族轮；真实分布同类占比 **0/1542**。
- 结论：**远端降幅对本交互形态无外部效度**（`EXTERNAL_VALIDITY_GAP_CONFIRMED`）。这正是用户说的「脱离封闭系统看真实情况」。

## 4. 数据驱动的唯一候选（不是结论）

真实分布里最高频的 23.4% 是 **D 类迭代驱动**（`继续/持续/下一轮`…），而 `继续/持续` **不在**认可族
⇒ 结构性不可跳。若把族扩到「迭代驱动」并配可证等价的判定，真实流量上潜在可跳轮 ≈ **23.4%**。
风险：这类消息就是「让我干活」的指令，跳过=不执行 ⇒ 必须先证明「跳过即执行」等价，故本轮**只登记候选**。

## 5. 诚实边界

1. 语料 = **用户↔Hermes agent** 的真实对话；被测门在产品（`agenthost`）链上 ⇒ 结论限「同类交互形态」，不直接等同产品终端用户分布（那需要部署端日志，通道 A1）。
2. 标签 = 规则分类（D/O/S + 采纳/纠正/换题），可复算但有噪声，未做人评校准；`correct` 关键词命中含「为什么/依据」，其中部分是**追问**而非纠错。
3. 本轮**无真机 token 读数**：对侧 R448 真机在跑（llama-server 活），按并发铁律本侧零 dotnet、不占轮号。
4. think-memory 的 4 个缺陷（D-TM1..4）只做**检测**，未修；`verdict` 只说「当前不能作真值通道」。
5. 语料含用户真实文本（本机、不外传）；`real-corpus.jsonl` 21.6 MB 未提交（`eval/rover/r449/` 保持未跟踪，等 R449 正式执行时决定入库形态）。
