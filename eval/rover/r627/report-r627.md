## 0. 一句话

R626 遗留的器具层缺陷 **P4-pos-prereg-form**（正控用**单路**口径去对**融合池**读数，实测 0.8409 < 0.90）本轮定位为
**比较形态失配**：换成**同形（RRF 融合）**口径后，独立 oracle 对产品生产口径池（`B10`）**逐例复现 120/120**
（agreement **1.0000**、命中 **88/88**、逐例差异 **0**）——同时本轮**又自捕一件同类器具缺陷**：负控指标 `agreement(臂, 产品)`
对被破坏的臂**不敏感**（配错臂仍 0.8333）⇒ 照原样 FAIL、阈值不下调，正确形态单列 `checks_posthoc`。

## 1. 缺陷定因（两件，均为**器具层**）

| # | 缺陷 | as-written | observed | 定因 | 处置 |

| 1 | `P4-pos-prereg-form`（R626 遗留） | 正控「hit 侧独立 dense **单路** rank_any@10 ≥ 0.90」 | 0.8409（**FAIL，不翻案**） | 出题前提隐含「产品池 ≈ 独立 dense top-10」，而产品池 = dense 与 lexical 的 **RRF 融合** top-10（`RAGRecall.cs:316-353` + `RrfFuser.cs:22` k0=10、双权重 1.0）⇒ 单路与融合池**本不必一致** | 本轮改为**同形口径**：同形 agreement **1.0000** ≥ 0.90 ⇒ **PASS**；R626 旧读数**并列保留**、不改写 |

## 3. 事后诊断（`checks_posthoc`，信息项 · 不进 rc）

**3.1 负控指标的正确形态**（承缺陷 2）：判别力应取**臂间差异量**——
`symdiff_hits_vs_产品 = 0 / 15 / 20 / 29`、`命中数差 = 0 / −13 / −20 / −29`，两种形态都**单调可辨**；
而 `agreement` 形态在 N2 上给出 0.8333 的「高分」⇒ **该指标形态对坏臂无牙**。下轮负控一律改差异量形态。

**3.2 归并/截断次序**（文献 2609.15143v1 的机制假设，本仓形态检验）：

| 形态 | 定义 | 命中 /120 |
|---|---|---|
| 早归并（现产品） | 先 `Take(TopK=10 单元)` → 再 chunk→parent 归并 | 88 (0.7333) |
| 晚归并（替代） | 全量归并 → 取前 10 **父文档** | 88 (0.7333) |

⇒ **gain = 0/120 ⇒ 该轴在本仓被证伪**，「同父多块白占槽位」确实存在（早归并下池内父文档数 < 10 的查询 **23/120**）
但**不承重** ⇒ **不开实现**（零产品改动、零测量）。`pool_len_delta_median` 恒 0 是**退化字段**（两形态都恰好取 10 个父文档），
已在件内显式标注并换成有判别力的等价量（`pool_len_early_lt_10_n`）。

## 4. 诚实边界

1. 本轮**无任何能力/成本增益宣称**：零产品源码改动、零远端调用、零真机臂、零新增夹具。
2. `agreement = 1.0` 是**器具自证**（同形复现产品），**不可读作能力达标**；该 oracle **与产品同形 ⇒ 同时使用它不能作能力面的独立 oracle**（R626 的能力面上界 oracle 用的是**异形**信号 BM25 + 块粒度 dense，两者用途不同、**禁混用**）。
3. **未测**：tokens（调用 / 新算 prompt / completion）· 缓存命中率 · 轮数（本面零 LLM）· codex 外部真值臂（本地检索面无远端题面）。
4. 与 R623/R624/R625/R626 **禁相减、只并列**（判据器改版禁相减）。
5. **面 4 仍未达标**：生产口径 R@N **0.7333 < 0.9**；P@10 = 1/k 算术不可达 ⇒ 达标路径处置**待用户放行**（升级用户三类之一）。
