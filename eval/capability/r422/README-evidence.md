## 4. ★ 预注册判据被证伪（本轮核心诚实项）
- `B2`（**红**）「同词元命中集内分数不再并列」——实测 3 份命中里 **两份词元数相同**（≈90，同一题的两个采样），
  故**任何仅依赖文档长度**的归一都不可能为其分档。这不是实现缺陷，是**预注册判据过强**：把「分档存在」误写成「两两不同」。
- `B5`（**红**）「`|d|_est` 与整数相差 < 0.02」——容差与**渲染精度**（`score=F4`，4 位小数）不匹配：0.0590±0.00005 ⇒ 相对误差 8.5e-4 ⇒ `(S/s)²` 误差 ~0.18% ⇒ 90×0.18% = 0.16 > 0.02。
- 处置（按 R402 归因纪律）：**不改 B2/B5 文字、不重跑凑绿**，`verdict.verdict=PARTIAL`、`verdict.pre_registered_failures=["B2","B5"]` 如实落盘；
  另立 `B2b/B5b` **标记为事后**（`checks_posthoc`，Verdict 里与主判据分段打印），仅作机理对账，**不得**当作主判据复用。
- **宣称收窄（`claim_scope`）**：「分数与文档词元数成反比、命中集合不变、极性不变量保持；**等长文档仍并列**（后续候选：tf / 语义信号）」。

3. 3 份语料不足以估「等长并列」的实际影响面；n=3、单批次、单机。
