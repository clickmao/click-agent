# R421 证据：跨会话检索的**否定极性**（`/recall 不存在` 不再召回到只断言「存在」的文档）

**轮次**: R421 · **分支**: A（有任务） · **计划项**: R420 下轮候选 ①（否定 / 词面重叠假阳性）
**一句话**: R420 真机读数暴露「`/recall 不存在` 命中 2 条**只断言存在**的文档」⇒ 打分层把`存在`与`不存在`当成同一个词元。本轮做**否定极性**（否定标记紧邻的词元带极性前缀，与肯定词元不互 match），并在**逐字节相同的语料**上用「治疗臂 vs 撤销修复负控臂」取得成对读数。

## 3. 真机读数（`/recall`，同 harness、同语料、逐查询独立跑）

| `recall_query` 打点 | 1/查询 | 1/查询 |

命中集：`cli-6bf6dc8d` + `probe-0914125816-p004` + `probe-0914125831-p005`（三者都在记忆里断言「存在拓扑序」这类**肯定**命题）。

**读数可被模型解释（不是只记录）**：`score = Σ Idf(t) / √|qSet|`，`Idf = ln(1 + n/(1+df))`，n=3 文档、`存在` df=3 ⇒ `Idf=ln(1.75)=0.5596`；负控臂 `不存在` 只匹配到 `存在` 一词元 ⇒ `0.5596/√2 = 0.3957`；`外星词根zzq不存在` 有 6 个词元 ⇒ `0.5596/√6 = 0.2285`。**三个读数与公式逐位吻合** ⇒ 缺陷定位在「词元层把否定词与肯定词混同」，不在解析/归属层。

**语料卫生（A9）**：fixture 三文件（R420 命中文档原样快照，sha256 见 `verdict-r421.json`）在两臂跑后摘要不变 ⇒ 读数是只读的。

## 4. 本轮两个仪器发现（都是"读数不可信"类，非被测不达标）

1. **渲染不可机读**（A12，已修 + 单测回归）：命中行 `N. <id>  score=…` 与下一行的片段被粘成同一行 ⇒ 任何按行解析命中集的解析器**只能取到第 1 条**。本 harness 第一版就这么踩到（治疗臂 `存在` 读成 1 命中）。修法：片段后补 `AppendLine`，并把「行可寻址」写成断言（`Render_Is_Line_Addressable_One_Hit_Per_Line`）。
2. **R420 的口径更正**（A13）：R420 记录「`存在` 与 `不存在` 分数同为 1.5660」，本轮受控读数显示**分数不同**（0.5596 vs 0.3957），真正相同的是**命中集合**。缺陷结论不变（打分对否定无感），但「分数相同」这条读数**不可复现**，已按新口径登记。

## 6. 诚实边界（没测到的就说没测到）

1. **极性作用域只有「标记本身 + 紧邻 1 个二元组」**：`不认为存在环` 这类「否定在句中、`存在` 距离 >1 字」的句子**未测**（当前实现只挂到 `不认`、`认为` 两个二元组，`存在` 保持肯定）。
2. **`别/勿/莫/甭` 未纳入**（`别` 与 `识别/区别/特别` 高频碰撞，纳入会带来召回损失）——这是**有意的取舍**，不是遗漏。
3. **`无/非` 的复合词碰撞未量化**：`无线`、`非常` 会被当作否定标记 ⇒ 极性对称（查询与文档同侧处理），只会损失召回、不会制造假阳性；但损失量**未测**。
4. **打分无长度归一**：同一词元命中的所有文档分数**相同**（本轮三份文档同为 0.5596，短文与长文不分）⇒ 命中集合内的相关度区分度**不存在**，这是本轮**未解决**的候选问题。
5. **样本 = 3 份文档 + 4 条查询**，非分布量测；命中集与文档数都小到可以逐条人工核对（这既是优点也是局限）。
6. **r1 增益 / token 下降 30% 这一主线 KPI 本轮未触碰**：`/recall` 是本地确定性指令，`llm_call==0`（A10）恰说明它**不产生** LLM 调用 ⇒ 它不是 token 下降的贡献者，而是「不必要远端调用」的**抑制器**（把本该问远端的问题在本地答掉）。
