# 通用代码反模式规则 (Critic Rules R01-R08, 语言无关)

## R01 循环内堆分配代替取值 ★最易犯

- **反模式**: 循环体内为取少量固定值而构造临时集合/数组/字典字面量。
- **机制**: 每次迭代一次短命堆分配 → 回收压力; 语义是"取值稳定", 分配是纯副作用。
- **修法**: 直接具名取值/引用 (按语言取惯用写法, 见映射表)。
- **例外**: 确需集合语义 (传给集合 API) 时合法; 单元素常量可豁免。

## R02 字符串累加拼接进循环

- **反模式**: 循环内对不可变字符串做 `+=` 拼接。
- **机制**: 每次拼接产生新串, 中间串链导致平方级开销。
- **修法**: 用可变构建器, 或先收集片段再一次性连接。

## R03 异步函数返回空 (非事件处理器)

- **反模式**: 异步函数返回空且不交出可等待句柄。
- **机制**: 异常不可观察; 调用方无法等待/组合。
- **修法**: 返回可等待句柄; 仅 UI 事件处理器保留空返回形态 (例外)。

## R04 阻塞等待混用异步

- **反模式**: 异步调用后同步阻塞取结果。
- **机制**: 同步等异步 → 死锁面 + 线程/事件循环饥饿。
- **修法**: 全链保持可等待传递; 只在最外层入口阻塞。

## R05 空捕获吞异常

- **反模式**: 捕获块体为空, 无记录无注释。
- **机制**: 异常信息蒸发, 调用方无从排查。
- **修法**: 至少记录/打点; 明确豁免理由注释。

## R06 计数判空代替存在性短路

- **反模式**: 对可枚举集合用"计数大于零"判断非空。
- **机制**: 计数会全枚举; 判空只需存在性检查。
- **修法**: 用存在性短路检查; 已知长度的容器可直接取长度。

## R07 浮点结果直接相等比较

- **反模式**: 对浮点计算结果用相等运算判定。
- **机制**: 二进制表示误差 ⇒ 相等判定对计算结果几乎必假。
- **修法**: 容差比较; 金额用整数/定点表示。

## R08 资源未确定性释放

- **反模式**: 打开文件/连接/锁后依赖回收器释放。
- **机制**: 句柄泄漏至回收为止 (非确定性); 锁/文件残留。
- **修法**: 用确定性释放构造 (按语言取惯用写法, 见映射表)。
