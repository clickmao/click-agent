# 校验基建自身的假阴性形态（通用）

**何时用**：对账/校验/自检**全绿**却与观测矛盾时；新增一条"一致性断言"之前；改完校验脚本准备说"验证通过"之前。
**核心命题**：绿不是证据，**判据的可证范围**才是证据。一条断言只能证明它字面覆盖的那个命题。

## §1 两侧互算摘要一致 = 只证明"传递无损"，不证明"内容正确"

**失效机制**：上游把待送内容算出摘要 A，下游对收到的同一份字节算出摘要 B，断言 A == B。
这断言对**内容本身错误**零分辨率——错误字节在两侧恒等，摘要照样相等。

**判据**：
- 内容正确性必须由**独立实现**对**同一份原始输入**（原始素材 + 规格/参数）各自产出后**逐字节**对照；自己算自己不算证据。
- 只能自算的一侧，必须把"权威源"（上游原始素材 + 权威规格）作为对照的另一侧，而不是拿自己的输出当参照。
- 不要把"两侧摘要相等"写成"内容已验证"；写成"传递无损"。

**回归哨兵（形态断言）**：凡承载语义的固定符号，断言其**形态**，不只断言其存在。
- 典型形态：某符号位置出现了"标识符的数字编号"的字面量，而不是该符号本身。
- 实测形态：把标识符的**数字编号**代入模板变量，产物前缀变成一串字面数字；因两侧摘要算法用的是同一份错误字节，一致性断言全绿。

**双向回放**：造一个"故意错一位"的样本，断言必须**红**；不配负控的一致性断言等于没检。

## §2 新增顶层定义插进函数体会静默吞掉函数尾部

**失效机制**：新定义被插入函数体内部却回到第 0 列 ⇒ 语法仍然合法 ⇒ **编译/解析全绿**，但该函数尾部整体变成新定义的函数体、永不执行。产物不再落盘，退出码 0。

**判据**：
- **语法通过 ≠ 结构正确**。改完必须**真跑一次并核验产物**（产物存在 + 时间戳/内容/行数），不是只看退出码与编译结果。
- 结构性核对：取语法树，断言"顶层定义集合符合预期"且"目标函数末行 == 文件尾部附近"。
- 一次插入多处时，逐块核对比行号算术可靠（行号会因前面的插入而漂移）。

## §3 聚合循环的计数器在循环体内自增 ⇒ 零迭代假数据

**失效机制**：循环边界取自一个"本应由循环维护"的计数器（在体内自增）⇒ 循环零次执行 ⇒ 产出 0/0 的假读数据，且不报错。

**判据**：分母/迭代次数必须**独立于被测对象**算出；空集合要显式报错（"没有样本"≠"全部通过"）。

## §4 免疫动作（改动校验基建后的固定动作）

1. 写下这条断言"能证明什么、不能证明什么"，不能证明的部分另配独立对照；
2. 每条一致性断言配一个**该红必红**的负控样本；
3. 改完校验脚本**真跑一次**，核验产物本身（存在/数量/最新时间），不看退出码；
4. 汇总类脚本补"空集合显式报错"分支；
5. 结论措辞与可证范围一致：说不出证据链就别写"已验证"。
