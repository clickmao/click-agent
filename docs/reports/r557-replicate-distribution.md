## 3. wythoff 失分定因 (离线复判 + 中继 dump, 零远端调用)

**复判器具正控**: 把 R556 四窗 A1 快照逐窗回放到独立物化副本上跑隐藏 58 用例 ⇒ `58/58, 51/58, 58/58, 58/58`, 与 R556 登记读数**逐位一致** (器具可信); w91 的 7 条失分设为 `wythoff#43-public,44-public,45,47,48,49,50`。

**逐条实测 vs 期望** (w91/A1): `21 25`→`LOSE` (期望 `WIN 15 15`)、`10 9`→`WIN 8 8` (期望 `WIN 0 3`)、`18 8`→`LOSE` (期望 `WIN 5 0`)、`12 18`→`LOSE` (期望 `WIN 1 0`)、`11 25`→`LOSE` (期望 `WIN 0 7`)、`18 17`→`WIN 16 16` (期望 `WIN 0 6`)、`7 21`→`LOSE` (期望 `WIN 0 17`)。

**定因**: 该窗解里的必败点判据 `_is_lose` 取 `k = int(phi × 小堆)` 再试探 `k±1`; 正解取 `k = 两堆之差` (`x == floor(phi·(y−x))`)。⇒ 必败点大面积漏判 ⇒ 既出现「该赢却报 LOSE」, 也出现「合法制胜但不是字典序最小」。

**机制侧 (既有开关的实态, 不是猜测)**: 该窗 `calls=2 / exec_repairs=1 / stage=expect_stdout_exhausted`, 即 **执行证据回灌修复被行使且用尽**; 同窗 probe 也跑了 (`public_probe_ran=1, public_probe_failed=2/8`) 但 `MAX_PROBE_REPAIR` 未设 (剂量轴 R551–R553 已判无增益) ⇒ 无预算。**首答与修复答的 wythoff 实现互不相同、但都错** (首答 = mex 集合构造 + 无排序查表; 修复答 = 上式的 `_is_lose`) ⇒ 缺口在**生成/修复面**, 不在契约面、不在夹具。
