## 4 · 结论（如实收窄）
1. **R413 判据不达标，且方向相反**：相对外部真值，本侧中位调用数 1.71×、有效 token 3.05× ⇒ **不宣称任何 token/调用降幅**。
2. **纪律无增益，且 R522 的「19→4」是窗口方差**：同一 A1 臂在三同输入窗给出 17 / 4 / 12 调用（摆动 4.25 倍）；A1/A0 中位比 1.5（逐窗 4.25/0.5/1.0，符号翻转）⇒ 该「降幅」不具因果性，单窗读数不可作能力结论（R522 已如实收窄，本轮给出量化依据）。
3. **质量面未降**：A1 三窗 58/58 且 ≥ A0 ⇒ 「token↓ 且质量不降」中只有后者成立。
4. **外部真值自身不稳定**：codex 三窗用例 58/46/58（w2 错 12 例 wythoff 隐藏用例）⇒ 单窗交叉对比在本任务族上无判别力；后续轮次必须报逐窗读数 + 极差（本轮已落地）。
