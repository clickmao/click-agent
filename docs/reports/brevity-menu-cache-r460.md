## 3. 命中率算术（为什么不达标 / 97% 的可达条件）

`hit% = 1 − 新内容/前缀`。R460 主动把前缀压小（每调用 prompt 均价 3,231 → **3,066**），新内容≈302 tok 未同比压缩 ⇒ 比率反而下降。要在 3,066 tok 前缀上取 97%，每轮新内容须 ≤ **92 tok ≈ 275 字符**（含模型回复本身 ~150 字符）⇒ 唯一杠杆 = 压 `[SessionMemory]` 块与 `[下轮预估]` 块。**R461 靶点。**
