## 1. 因果链（为什么是这一轮）

R544 把公开用例回放挂在 `exec.Rc==0` 出口 ⇒ 同窗 3 个 on 臂里只有 1 个走到回放点（另 2 个在**计划执行阶段**就 `rc=5`） ⇒ 预注册 J1 判 FAIL =「机制只在小概率出口生效」。
R545 的修法：**只要执行器已把产物写到盘（work 文件数 > 0），就回放题面公开用例**（`exec.Rc==0` 不再是前提），并把**触发那一刻的出口 rc** 记进台账（`trigger_rc`，`-1`=未触发）与原因（`public_probe_reason`），供机检区分「真未触发」与「无产物可测」。

## 5. 诚实边界

1. **J3 收窄照原样保留**：质量轴**无增益证据**（用例中位 47 < 53），n=5 单窗、离散结局（rc ∈ {0,5,8}、用例 0–58）主导方差 ⇒ 只宣称「触发面真生效」+「回放零代价」，**不宣称质量提升**。
2. **判据器实现修正（同窗同产物重算，不动读数）**：预注册 J3 是两维非劣（全绿臂数 ∧ 用例中位），初版实现只算前者 ⇒ 补齐后判「收窄」，已在 `readings-w1.json` 分列 `all_green_not_worse` / `cases_median_not_worse`。
3. **旧路径列跨窗不可比**：R544 单样本 34 调用 / 714,287 tok / 46/58 vs 本轮 3 样本 4–5 调用 / 34,657–53,685 tok / 56–58/58 ⇒ 该列**自身是方差源**；且本轮其质量前提（我方满绿 ∧ 旧路径不满绿）不成立 ⇒ **无「r1 更省且质量不降」可宣称**。
4. **外部真值（codex-cli）仍缺席**：`g1` 形态 32 步上限已在 R523/R529 判不可用 ⇒ 主线四硬条件**缺外侧**，本轮为内部单变量 + 旧路径基线。
5. **公开面 8 条是必要非充分**：P1a（公开失败 2）隐藏 47/58 ⇒ 公开面漏检 45 条隐藏用例；「公开全过」≠整题正确（P1b/P1e 只是**同号**，非因果证明）。
6. **前置器 rc=1**：其口径是「任一臂-题不许错」⇒ 在随机模型下近乎不可达；本轮未擅自放宽（候选④：需先写后跑决定是否引入臂级阈值）。
7. 未测：探针预测力的跨轮/跨族稳定性（单窗 5 点）、role 轴对质量的影响、codex 外侧列、探针回灌预算与质量的关系。
