# 词法融合调参网格实验（裁决：停止）

- 日期：2026-09-14
- 问题（用户逐字）：「词法融合是否还再进行测试实验，是否还有必要进行？」
- 数据：`eval/bge/results/fusion-knob-grid-2026-09-14.json`（21 变体全量读数）
- 冻结口径：1299 语料 / 120 查询（1 条查询 = 0.8333pt）

## 预注册判据（跑之前写死）

- 指标：r@10
- 显著性下限：净增 Δ 条时最小 McNemar 双侧 p = 2^(1−Δ) ⇒ Δ=2→p≥0.500；Δ=4→p≥0.125；**Δ=6→p≥0.0312**
- 裁决规则：**最好变体相对冻结版净增 <6 条 ⇒ 可判定空间为零 ⇒ 停止调参实验**
- 冻结参照：lex+base RRF `k0=10 w=1:1` = 102/120 = 0.8500（r@1 0.5333）

## 结果

| | 命中 | r@10 | r@1 |
|---|---|---|---|
| 冻结版 `lex+base k0=10 w=1:1` | 102/120 | 0.8500 | **0.5333** |
| 最好变体 `lex+base+small k0=10 w=1:1:0.5` | **103/120** | 0.8583 | 0.5167 |
| 两路 oracle 上界 union@10 | 104/120 | 0.8667 | — |
| 三路 oracle 上界 union@10（加 dense-small） | 104/120 | 0.8667 | — |

- 21 个变体里最好者只比冻结版 **+1 条**，且用 r@1 掉 2 条换来；其余变体均 ≤0 或与冻结版并列。
- `k0` 单调性：k0 从 10 → 20 → 60 全部**下降**（0.85 → 0.8333 → 0.80）⇒ 冻结值已在峰侧。
- 权重单调性：`w=2:1`（偏词法）一路崩（0.7833–0.8417）⇒ 语义侧权重不能再降。
- **加 dense-small 第三路 union@10 零新增覆盖**（104 → 104）⇒ 同家族第三路无互补性，此路证否。
- 距两路 oracle 上界只剩 **1 条**。

## 裁决

**词法融合不必再做调参/组合实验。** 三条独立理由：

1. **可判定空间为零**：最好变体 +1 条 << 显著性下限 6 条（数学上不可能显著）；
2. **已到上界**：冻结版吃到两路 oracle 上界的 102/104 = 98.1%，剩 1 条；
3. **同族第三路零增量**：dense-small 加入 union 集合覆盖不变 ⇒ 不是"再加一路就好"的问题。

冻结配置 `k0=10 w=1:1` 即该组合最优点（同时是 r@1 最高点 0.5333）⇒ **冻结上线，不再实验**。

## 唯一能改变该裁决的两件事（诚实边界）

1. 换**不同家族**第三路（非 bge-small/bge-base 同族），且能吃到剩余 16 条未命中里的 **≥6 条**；
2. 评测集从 n=120 扩到 **n≥800** 真实标注，把 ≤3.34pt 的增益拉进可判定区。

两条都**未做**（成本/usability 门槛见 `docs/reports/bge/base-finetune-final-2026-09-14.md`）。
