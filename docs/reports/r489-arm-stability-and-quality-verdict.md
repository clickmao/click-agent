## 6 · 诚实边界

1. **n=3 跑 / 单夹具**：只给臂内摆动，不给上游漂移分布；无置信区间；跨轮一律不相减（H0 +19.85%）。
2. **H5 为预注册缺陷**（B 臂 gate=off ⇒ 模板 0 是应然）：保留 FAIL，不回改预注册；post-hoc 修正读数 = R1/R2/R3 各 4 轮模板，与夹具 ack 轮数一致。
3. **B 臂 harness 泄漏**已修但**首跑证据保留**：`teardown-Aroleb.json`（`--reap` 为 R1..R3 新增）；B 与 R1..R3 的 harness sha12 = `cd2d2cef` 有差异，故 B 的 teardown 面与 R 臂不同源。
4. 文案裁决改变**用户可见文本**（21→3 字）⇒ 已单列 before/after；对 token 的影响只在下一轮前缀长度，非本轮 KPI 来源。
5. 质量面为**类别感知机检**（非法模板 0/12 + 遥测↔源码字符绑定），**不做人工语义评分**。
6. 去空正文口径是 **post-hoc 单列**（预注册 H1 FAIL 保留）；上游空正文属**供应商行为面**，本机不可控。
7. 候选⑤/⑥ 未做 = **改链/改默认通道 ⇒ 换被测二进制 ⇒ 与本轮稳定性测量互斥**，需独立 A/B 窗口。
