## 1. 并池合法性（P1）与一处**必须纠正的派生错误**

- 判分器 sha、题集 sha、全部 agent 臂二进制 sha **各唯一** ⇒ 并池合法；33 窗、58 例、同题面同夹具。
- **纠正**：`R565` 的臂名 `B0` 是**环境标签**（env 未设键），不是剂量 0。产品默认档由**源码派生**
  （`src/agent/r1/R1Options.cs`：`MaxExecRepair = 1`）⇒ `R565B0` 属**剂量 1**。
  若沿用臂名当剂量，池构成与逐例读数**全错**（这正是「规则端口必须源码派生、禁手抄」的又一实例）。
- 另一处**自捕**：首版池按「非 C1 臂」过滤 ⇒ 把 0/1/3 三档混进同一池，例窗数 `2784 ≠ 27窗×58例`。
  算术自检（例窗数 = 臂窗数 × 例数）当场暴露；修正为「只统计该剂量自己的臂（由登记表机取）」。

## 2. 预注册判据的判决（原样，不改阈值）

| 判据 | 判决 | 依据 |
|---|---|---|
| P1 池化合法 | PASS | sha 各唯一 + 逐条对账 |
| P2 逐例稳定（混合例 ≤ 6） | **FAIL** | dose0/dose1/dose3 混合例 = 58/58、15/58、15/58 |
| P3 逐例剂量敏感（Fisher p<0.05） | PASS | n_sensitive = 0（0v3 与 0v1 均 0） |
| P0 非平凡 | PASS | 族级读数集合大小 3；逐例读数互异 |

**P2 判红的根因是判据自身**（自捕，非被测缺陷）：在均匀失败模型下，池内「全过例数」期望为
`58·(1−q)^n`，dose0 期望 **53.68** ⇒ 期望混合例仅约 4.3，阈值 6 只在失败率 <1% 时才可达。
同一个数还给出本轮最有信息量的读数——**观测全过例 0/58，z = −26.84 ⇒ 过分散**：
失败几乎覆盖每一例，因此**单窗逐例读数不可作读数**（与既往「跨窗摆动 > 臂间效应」同源）。
修正后的判据形态（下轮预注册）：`观测全过例数 ≥ 均匀模型期望 − 2σ`。

**P3 为何不能当结论**：逐例面的最小可分辨效应 `Δ_min ≈ 29~39pp`（n=27 vs 15/12）
⇒ 「未检出」不等于「无差异」。凡在不可分辨面上得到的 0，都只能记作**未可判**。

## 3. 补记面（明示事后性）：剂量档**有平均增益**

预注册只覆盖了逐例面，而逐例面不可判 ⇒ 补两个有分辨率的面，**预注册判决不变**：

| 面 | 剂量 1 vs 0 | 剂量 3 vs 0 |
|---|---|---|
| 同窗配对（无窗混淆，McNemar 精确） | +4.89pp（p=0.0046） | **+10.46pp**（p≈0） |
| 剔「臂级崩溃窗」后 | +4.89pp（p=0.0046） | **+4.31pp**（p=0.0013） |
| 族分列（剔除后） | 仅 wythoff +18.89pp | sub +5.10pp / wythoff +11.90pp |
| 逐窗回退 ≥3 例的窗 | 1/6（w130） | 4/15（w107、w108、w131、w135） |
| 同窗配对下对 codex 的差距 | 47 → 30 例窗 | 140 → **49 例窗（收窄 65%）** |

- **臂级崩溃窗**：`w104` 的剂量 0 臂 **0/58**（同窗剂量 3 臂 56/58）⇒ 运行级崩溃，混入均值会把效应放大。
  该规则在看到数据后才表述 ⇒ **两个数并列报，不作挑选**（含 +10.46pp / 剔 +4.31pp）。
- **与 R566/R567 的单窗判决不矛盾**：那两轮判的是「**逐窗不回退**」（0v3 有 4/15 窗回退 ≥3 例）
  ⇒ **平均增益 ≠ 逐窗不回退**，两读数并列、禁相减。
- **归属**：并池面 `same_fail = 0` ⇒ 夹具同败分支排除；6 例独败（#45、#47、#48、#49、#50、#56）

## 4. 起手闸 `REQ=2753` 行使

| 步 | 读数 |
|---|---|
| S0 既有闸自带收尾 | mem 2697MB，blockers 空 |
| S1 起手前 3 样本 | 2704 / 2703 / 2701（顶棚 **2704**，极差 3MB） |
| S2 条款派生（MARGIN = R567 观测振幅 103） | **rc=2：顶棚 2704 < REQ 2753**（slack −49MB）⇒ fail-closed 不放行 |
| S3 判别带成对控制（确定性压制） | 同一状态：基础门槛 2650 **PASS**（2685MB）/ 条款 2753 **GATE_BLOCKED**（2694MB）⇒ **有牙，rc=0** |

- 缺陷族与 R564 的 `v1 常数 MARGIN=200 ⇒ REQ 2850` **相同**：只把「拍脑袋常数」换成
  「数据派生但**未夹上界**」。可支配余量 = 2704 − 2650 = **54MB** < 上一轮振幅 103MB。
- **下次规则**：`MARGIN := min(上一轮观测振幅, 顶棚 − GATE_MB − 安全地板)` ⇒ 本宿主 `min(103, 54) = 54` ⇒ `REQ = 2704`。
- 附带登记：常驻语言服务器（pyright 197MB + bash-language-server 171MB）沉默占用约 370MB；
  闸只回收年龄 >60s 者 ⇒ 顶棚随宿主负载区制变化（本轮 2704 / R567 轮 2861）。
