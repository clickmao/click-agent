AOT 教训（本轮实发、已入代码注释与单测）：
1. **STJ 反射序列化在 AOT 被禁用**（实测 `InvalidOperationException`）⇒ 落盘闸必须手写零反射 JSON 转义；
2. **`Encoding.UTF8` 建文件会写 BOM** ⇒ 必须 `new UTF8Encoding(false)`，否则下游 JSONL 解析器炸（本轮 s1 首跑即踩）。
