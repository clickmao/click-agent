## 1 因果链

R474 真端点双臂实测（同 AOT / 同 p12 网格 / 唯一变量=门控）暴露三处**真缺陷**：

1. **质量**：R 臂 12 轮中 6 轮模板应答、3 轮用户可见「模型未产出正文…」徽标，实质回答仅 3 轮（Arole 12/12 实质）；`mechanical:repeat→local` 轮（t6「再讲一遍。」/ t9「从头再说。」）**回放的不是正文**。根因：回放取「最后一条非空 Assistant」，而上一条正是空正文徽标 / 模板 ⇒ 以非实质文本充当答复。
2. **记账**：`llm_call_recover` 行缺 `prompt_tokens` / 缓存字段 ⇒ 产品自记账漏 15,458 prompt tokens（Arole 的 21.8%）。
3. **口径**：3 例 `effective_hit_rate > 1`（实测 `hit=2,944 > cacheable=2,900 ⇒ 1.0152`）—— 命中量超过同会话可缓存上界，说明命中来自**比上一轮更长的共享前缀**，K2b 对该轮不适用，>1 会污染红线统计。

## 2 判据（预注册，与 `prereg_r475.json` 一致）

- **C1** 纯复述轮若不存在**可回放的实质答复** ⇒ 撤销 Skip、降级远端（可见遥测 `repeat_degrade_remote`），**不得**以模板冒充。判据 = 结构门（降级分支与 `IsPureRepeat` 同点判定）+ 执行支同源门。
- **C2** 回放守卫三类拒回放：空/空白、`LocalSkipFallback` 模板、空正文徽标前缀（前缀单源于 `ModelQueueRouter.EmptyBodyBannerPrefix`，**不得**新建用户文本关键词表）；成对负控：实质答复必须判可回放。
- **C3** `effective_hit_rate > 1` 结构性不可能：`hit > cacheable ⇒ -1`，且该轮 `cache_channel` 归 `shared_prefix`（`ExceedsSameSession` 单源）。**真实 43 条既有读数零回归**（那些行 `last == 0` ⇒ 通道不变）。
- **C4** `llm_call_recover` 两处打点补 `prompt_tokens` / `cache_hit_tokens` / `cache_miss_tokens` / `cache_hit_rate`，取值同源于 `first`（禁二次估算；未上报 -1）。
- **C5** 中继器具落 `finish_reason` + 采样参数 + 逐调用恒等式（用于定位空正文；**另存新器具**，不动 R474 已绑定的器具 sha）。
- **C6** 双列并账：真值列 / 自记列硬分离，唯一跨列运算 `gap.*`，`recover` 缺字段 ⇒ `unreconciled`（**禁按 0**）。
- **C7** AOT 重发布后 IL 警告 0 + `env -i --version` 形态闸 rc=0。
- **C8** 全量单测 ×3 连续顺序隔离（每次 Failed 0 且执行数一致）。
