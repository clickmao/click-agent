# v0.64.0 · R444 · 廉价必要条件前置（¬Ack ⇒ Pass）的可证等价优化 + 短档/单跳档真值补测

状态: 已完成（判据于测量前预注册；结果见文末 §9）

## 0. 一句话

把已有的机械判定 `TurnGateJudge.MechanicalAck` 从**调用后否决**提升为**调用前守门**：不变量 `Skip ⇒ Ack` 由现网构造成立（`skip_rejected_nonack` 后置否决），其逆否 `¬Ack ⇒ Pass` 与 r1 判什么无关 ⇒ 对 `¬Ack` 轮**零差异地**省掉一次本地 r1 调用（R443 真值 ≈ 638.8 tok/轮）⇒ 直接压低「含本地真值」口径的分子。

## 1. 代码事实（改动前，行号为改动前）

| 位置 | 事实 |
|---|---|
| `src/agent/IndustrialAgentV2.cs:1478-1485` | `if (TurnGateJudge.MechanicalPass(message.Content))` ⇒ `Pass "mechanical:pass"`，**不建 prompt、不问 r1** |
| `src/agent/IndustrialAgentV2.cs:1486-1498` | `else` ⇒ `agent.modelqueue.TurnGateJudge.JudgeTurnAsync(...)`（本地 r1，**唯一**产生门本地成本处） |
| `src/agent/IndustrialAgentV2.cs:1500-1519` | 后置否决：`gateOutcome.Verdict == Skip && !MechanicalAck(message.Content)` ⇒ 改写为 `Pass "gate:skip_rejected_nonack"`（`local_turn_gate_reject` 事件带 `msg_sha16`） |
| `src/agent.modelqueue/LocalGenerationPort.cs:380-410` | `MechanicalAck` = 去掉标点/空白/符号后，余字符**全部**落在 `AckFamilyChars="好嗯行明白了知道谢收到多辛苦可以先就的"` 且 1 ≤ 长度 ≤ 10 |
| `src/agent.modelqueue/LocalGenerationPort.cs:538-570` | 门计数面：`RecordMechanicalPass/_skipRejected` + `LastBasis` |

**构造性论证**（这是本轮的承重逻辑，不靠测量）：设 `A = MechanicalAck(msg)`。现行代码在 `Skip ∧ ¬A` 时把判决改写为 `Pass`；在 `Pass` 时仍是 `Pass`。故 `¬A ⇒ 最终判决 = Pass`，与 r1 输出无关。因此把 `¬A` 判断前移到调用之前，**判决路径逐位等价**，唯一差别是不再产生这次 r1 调用及其成本。

## 2. 设计（改动内容）

1. `LocalGenerationPort.cs`：新增 `_mechanicalNonAcks`/`_prefilterViolations` 计数 + `RecordMechanicalNonAck()`（`LastBasis="mechanical:nonack→remote"`）+ `RecordPrefilterInvariantViolation()`。
2. `IndustrialAgentV2.cs`：新增 `else if (GatePrefilterEnabled && !TurnGateJudge.MechanicalAck(message.Content))` 分支（**开关默认开**）；后置否决支**保留**，命中即计 `prefilter_violations` 并落 `gate_prefilter_invariant_violation`（fail-closed，证明破坏时可见）。
3. 门遥测新增 `prefilter` / `prefilter_nonack` / `prefilter_violations` 三键（机器可检）。
4. **消融开关** `AGENTFRAMEWORK_GATE_PREFILTER=0` ⇒ 复原 R443 行为。此处「默认开」是生产行为本身（改进即位），开关仅作同网格单变量对照，与 R443 的「默认关 + 实验开关」方向相反，理由见 §5。

## 3. 约束

- 不改远端走向、不改内联块内容、不改落盘/回复文本 ⇒ 等价性判据要求**逐轮逐位**相同。
- `MechanicalAck` 语义**不得**放宽（放宽 = 引入假跳过风险）；本轮只改**调用顺序**。
- 单机内存 3.57 GiB ⇒ 三臂串行，禁并发 llama-server。
- 测量期间不跑 build/test（测量纯净铁律）。

## 5. 「默认开」而非「默认关」的理由（须与 R443 区分）

R443 的 `AGENTFRAMEWORK_GATE_REPLAY_SKIPPED` 默认关，因为「回放被跳轮内联块」是**非生产**的测量状态。本轮前置门**就是**改进后的生产行为，若默认关则等于交付一个不生效的改动；因此默认开 + 提供 `=0` 消融（= 复原旧行为）用于同网格对照。等价性由 §1 构造性论证 + D4 逐位判据双保险。

## 9. 结果（实测，2026-09-15）

- **KPI 达标**: M20 含本地真值降幅 **33.32% ≥ 30%**（R443 同口径 25.32%）；远端口径 46.18%；本地折算口径 39.24%。
- 门 r1 调用 **7 vs 17**（−59%）；本地真值 **7880 vs 12775**（省 4895 tok / 10 次 = 489.5/次）；判官侧不受影响（两臂同 4738）。
- **D4 逐轮差异 0/20 轮**（`actual` ∧ `G_calls/J_calls` ∧ 回复原文全同）⇒ 可证等价得到实测背书；两臂远端 tok 差 +4 = 已知路径混淆。

- AOT 0 IL（`e36d04d1` 与修复版 `c28e86d3`）；单测 **1287/1287**。

### 8.1 L4 首用即暴露的设计缺陷（已修，R444 实发）

首次提交时钩子自报 `WARN(L4): 陈旧心跳 (pid=… 不存活) ⇒ 放行`：心跳里记的是 **helper shell 的 pid**，`round_claim.sh` 退出后 pid 即死 ⇒ 新鲜心跳被误判陈旧（防线形同虚设）。修 = 新鲜度改为 **pid 存活 ∨ 龄 < TTL(5400s)** 的双条件，`release` 对新鲜心跳默认拒绝（`--force` 才可强释放），`claim` 亦拒绝覆盖新鲜心跳。实测：`status=FRESH age=16s`（pid 已死）✓；同写者提交 rc=0 ✓；异写者提交 rc=1（被拒）✓。
