## 0. 为什么必须做本轮（因果链）

1. R437 对「一轮任务按长度分档」只给出**模型外推**（承重读数：单次真诉求 −6.9%、短 28–30%、中 24–37%、长 17.8–41.1%），且其成本模型在建时就**缺一项机制**：它把跳过轮视作「只省下自己那一次调用」。
2. R438 修掉「本地消化轮把**从未发出**的内联块写进会话历史」后，实测跳到 p12 **37.37%**（预测偏离 0.0 pt），R439 长任务 V20 实测 **45.31%**，而 R437 模型对同格预测仅 ~27.6% ⇒ **偏差 17.7 pt，模型外推失效**（不是机制失效：机制本身被 R438/R439 证实有效）。
3. 因此「分档降幅」不能继续靠外推作答 ⇒ 本轮把**分档格真机跑出来**，并把「可跳轮位置」做成单变量。

## 9. 教训（语言无关, 已入 skill）

1. **目标轮必须冗余布置**: 产品澄清问句会吞并任意后续轮（实测 V2 t2 / V4 t3,t11 / V5 t3,t11,t15,t18 / V20 t4,t16 / V2b t2）⇒ 单点目标格得到的是「**未测到**」而非「测到失败」；有冗余时按 realized 配置跑前声明分支预测。
2. **A 分母必须取同网格同长度臂实测**；跨网格代理（逐文本/逐记录下标）会因历史不同构与多调用轮而位移（+9.25%）。
3. **常数律优先于线性外推**: 先测「是否随位置变化」再决定是否外推；本例 δ 与位置无关。
4. **「同长同文本」≠ 逐位同构**: 逐轮 prompt 仍受历史构成影响（最差 208 tok, 5.6%）⇒ 分母复现判据应写「总量级」而非「逐位」。
