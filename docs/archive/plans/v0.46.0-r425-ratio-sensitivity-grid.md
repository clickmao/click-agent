## 3. 预注册判据（跑测前冻结）

- **C-a（单调性）**: 降幅率 `r_k = (A_k − B_k) / A_k` 满足 `r_1 < r_2 < r_4 < r_6 ≤ r_8`（`A_k`/`B_k` = 该格两臂 `total_tokens_est`）。
- **C-b（闭式对账）**: 令 `ĉ = D_8 / 8`（`D_k = A_k − B_k`，k=8 为非实质轮最全格），预测 `D_k ≈ k · ĉ`；判据 `|D_k − k·ĉ| / (k·ĉ) ≤ 0.15` 对 k ∈ {1,2,4,6} 全部成立。**容差 15% 为预注册值**（吸收位置/历史长度效应）；不成立 ⇒ 如实登记「节省非按轮可加」，**不得事后放宽**。
- **C-c（假阴性 = 0）**: 每格**每个实质轮**在臂 B 至少产生 1 次远端调用；**每个跳过轮**在臂 B 产生 0 次远端调用。二者成对 ⇒ 非恒真。
- **C-d（跳过轮产物性质成对）**: 臂 B 跳过轮回复非空 ∧ 长度 ≤ 60 字 ∧ **不含**桩应答前缀（`桩应答`）⇒ 与 C-c 的「0 调用」互为佐证（回复不是远端产物）。
- **C-e（归因负控）**: 臂 B′（k=6，模型缺）满足 `|r_B′| ≤ 0.02` 且 `calls_B′ == calls_A(k=6)` ⇒ 无 r1 则增益归零 ⇒ 增益归因 r1 而非机械门。
- **C-f（分母自证）**: 臂 A 在每格对**每个**轮（含非实质）都有 ≥1 次远端调用（门关 ⇒ 无跳过）；若某格不成立，如实登记。
- **C-g（边界诚实）**: k=8 为边界格（全轮非实质）。若首轮（无历史）未被跳过 ⇒ 记 `k_eff = 实际跳过轮数 < 8` 并**单列**，不并入 C-b。

**事后判据（`checks_posthoc`，单列、不升为主判据）**: ① 每非实质轮平均节省 `D_k / k`；② `r_k` 对 `k/8` 的线性拟合斜率与 R²；③ 每格 `calls` 差分是否等于跳过轮数。
