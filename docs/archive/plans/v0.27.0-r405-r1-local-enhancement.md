## 1. 目标（把"增强"拆成可判定的三条）

- **A 正确性**: 输出从"乱码"→"数学正确 + 格式合规"（现状 `gen_text=11 ,` / `UNThis0one kil girlsforth0`）
- **B 可用性**: 0.458 tok/s → **≥2 tok/s（≥4.4×）**，使 56 题 NL 验证评测从 4.35 h 降到 ≤1 h
- **C 能力（同权重）**: 在同题集上正确率/弃权率/格式合规率**可测**提升（A/B 对照 + 预注册判据）

## 3. P1 提速（可度量门 —— 决定 P2 能否被验证）

**归因（实测）**: 瓶颈不是算力，是**每 token 重复读全部权重**（4.38 GB/token = 3.92× 模型体积）。

1. **权重常驻**（mmap + resident；1.04 GiB 落在 3.5 GiB 内可行）⇒ 把每 token 流式读降到 ≤1× 模型体积
2. **KV 复用 + 批 prefill**（R402 已建 `PartitionRows`/`threads`；步 1 实测 1.33×）
3. 线程度与 mmap 策略（R402 backlog 靶点）
4. 目标读数: 每 token 字节 ≤1× 模型体积；**tok/s ≥2**；56 题×128 tok ≤1 h

**验收**: `threads=1` 下 logits FNV-1a 64 哈希逐位不变（R402 口径 `97d959c1a00750d0`）+ 读数落盘 `eval/rover/r405/`。

## 4. P2 能力增强（不改权重，本机可行，逐条 A/B + 预注册判据）

| # | 手段 | 判据 | 成本 |
|---|---|---|---|
| 1 | 答案抽取 + 早停（自适应预算） | 抽取率 ≥95% 且题均 token ↓≥30% | 低 |
| 2 | self-consistency 投票 n=3/5/8 | 同题正确率↑ 且配对 McNemar p<0.05 | 中（×n 时间） |
| 3 | 可验证闭环（计算器 / z3 / 形式化内核） | 错答率↓ **且不引入假阳性**（反向负控） | 中 |
| 4 | RAG 上下文注入（bge 修好 + 融合线） | 冻结集 r@10 0.85（已逐位复现）+ 题级 A/B | 中 |
| 5 | 弃权/置信校准（Unknown 出口） | 隐藏拒答题上的**假通过率 = 0** | 低 |
| 6 | 演示库 few-shot（与推理**同一模板**渲染） | 冻结集 A/B，Δ≥6 条 ∧ p<0.05 | 低 |

**判据纪律（R399）**: 只认隐藏用例；失败必须分类；判定器必须有反向负控；回复原文落盘；**整题全对才算过**。

## 5. P3 权重级增强（本机不可行 —— 明确不做 + 依据）

- 微调 / 蒸馏: 64 h/epoch 起（1000×512）；Q4_K_M 上做 LoRA 仍需全精度计算图 ⇒ 本机不可行
- 剪枝: 必须在 FP16 上做且**需重训补偿** ⇒ 本机同样不可行；已量化的 Q4_K_M 上剪枝无意义
- 即便有算力: n=120 判据分辨率不足（Δ<6 不可显著）⇒ **必须先把评测集扩到 n≈897** 才能验收
- 本机**可做的前置准备**: ① 数据构造（同一模板渲染 + 教师轨迹采集）② 评测集扩充到 n≥800 配对样本 ③ 判据预注册 ④ registry 登记（sha256/角色/依据/回退指针）

## 6. 排除项（不做，附理由）

- 不用 R1 顶 p7b 的形式化证明位（R1 是自然语言推理模型；形式化位置它顶不上）
