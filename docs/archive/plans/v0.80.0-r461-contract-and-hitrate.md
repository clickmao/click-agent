## 3. 设计（机制，非关键词补丁）

1. **契约声明不上前台**（`FormalPromptContract.SplitFacing`）
   - 剥离对象：`clickproof` 围栏块（含闭合行）、裸 `clickproof` 头 + 紧随的 `premise`/`goal` 行、`no_formal:` 行。
   - 剥离时机：段路由 / 产物修复 / 承接兜底**之后**、收口判定**之前** ⇒ 验证面已消费过声明，机检不受影响。
   - 声明不丢：进 `contract_declaration_hidden` 遥测点（`decl_chars` / `facing_chars`）。
   - fail-safe：剥离后正文为空 ⇒ 返回原文（宁可少剥，不给空回复）。
2. **零字节产物可见**（`ContinuationBrief.AppendFact`，块与问句共用）
   - `bytes == 0 && first == ""` ⇒ 渲染 `name=(空)`。诚实边界：标空只让缺口可见，不阻止模型编造。
3. **记忆写入清洗**（`StoreToMemoryAsync`）
   - 只存 `SplitFacing(...).Visible` ⇒ 下一轮召回的 Q/A 不再带 `no_formal:`/`clickproof`（去污染 + 省 token）。
4. **每轮新内容预算收口（命中率的算术杠杆）**
   - `NextTurnForecast.HeaderTaskPreviewChars = 24`（上轮任务预览；完整文本在 `[SessionMemory]` 任务方向，去掉重复征收）。
   - `SessionMemory.DefaultMaxChars = 400`（原 1000）、`MilestonesInPrompt = 2`（原 4）。
   - `ContextAssembler.MemorySourceBudgetTokens = 120`（原 500）。
   - 三处用 `R461_Injection_Budget_Locks` 机检锁住（改了必须走一轮重新测量）。

## 4. 约束

- 禁关键字表：剥离走结构前缀（围栏/行首标记），承接判定仍复用既有 EvidenceGate 判据。
- 器具只读**实发全量消息**（`ADAPTER_DUMP_FULL=1` → `full-*.json`），缺文件报 VOID，禁重建 prompt。
- 同环境同输入：夹具与 R458/R460 逐字节同源（`/tmp/r457_env` pristine 8 文件），唯一差异 = 二进制。
- AOT：改链代码后必重发布 + `env -i` 自启 rc=0；形式门禁真名 + 断言执行数 > 0（防假绿）。
