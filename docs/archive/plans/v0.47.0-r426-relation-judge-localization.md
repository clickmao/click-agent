## 6. 诚实边界（预声明）

1. 「降幅 ≥30%」仍是**本 8 轮脚本族**的形态证据，不外推；判官本地化对**任意**任务族的效果未测。
2. token 为桩侧 `字符数/2` **估算**（非真 tokenizer）；两臂同口径 ⇒ 比值有效。
3. C7 是**一致性**，不是**正确性**：无人/大模型金标 ⇒ 不宣称本地判官「更准」；若一致率不达标，如实登记「本地判官不可替代远端判官」，并保留判官远端兜底路径。
4. r1 判官会消耗本地 CPU（门已如此）；对**用户可见时延**的影响本轮未测（判官在后台 `Task.Run`，`IndustrialAgentV2.cs:1621`）。
5. 本地判官的 `kind` 只在「解析出字母」时生效；解析不出 ⇒ 远端兜底 ⇒ 该轮**不省**调用（宁可多走远端，不猜）。
