## 2. 首批修复（本轮）

### F1 跨会话检索（对位 `session_search`）— 新增组件

缺口 #1 是**同一根因**的另一面：项目“能存不能查”（会话记忆落盘但无检索），与 exp5 教训表“前端无推送”、exp1“无统一缓存/索引”同族。本轮新增 `SessionHistorySearch`：

- 纯 stdlib 确定性打分（字符二元组 + 整串命中 + IDF 加权），**零 LLM、零反射、AOT 友好**；
- 只读 `ISessionMemoryStore.EnumerateSessionIds()/Load()`，不改存储格式；
- 诚实边界：检索面=**会话记忆摘要**（`LongTermMemory`/`GoalText`/`KeyEntities`/`Constraints`/`Milestones`），非逐轮消息（逐轮消息当前未落盘）。逐轮消息落盘 = 登记为 L3 前置。

### F2 “宣称≠实现”诚实化（#11）— 文档纠偏 + 接线登记

`skills/critic-rules/SKILL.md:82` 声称运行时扫描会复核，实际生产 0 调用。处置：
- **立即**把文档改为真实状态（未接主链 → 知识镜像仍有效，但不得称“双保险”）；
- **接线**（在主链末端跑静态复核并按 L1 标注呈现）登记为 L3 待办，避免“又一处凭文档假装已实现”。
