# v0.78.0 · R458 — 承接轮人性化：像人一样先承接事实、再反问「继续什么」

状态: 已实施 (R458)

## 1. 来源（用户令，逐字）

> 「我看到报告了，感觉目前开发研究的方向是正确的，但得做一些人性化的补充，比如t5感觉codex更胜一筹，
> 比如一个人对另一个人突然说一句，"继续"，另一个人不明所以，肯定就会反问"继续什么"」

参照物 = codex R455/R456 冻结读数（T5 逐项列已完成产物 + 收尾问句；T6 只回一句「已写入 `first.txt`：…」）。
我方 R457 实测缺口：

| # | 现象（落盘证据） | 层 | 修法 |
|---|---|---|---|
| H1 | T5 澄清问句是**固定示例菜单**（`(如: 搜索/写文档/执行命令/分析数据)`），不含任何"我们手上有什么" | 门面 | 问句**接地**：候选与措辞由工作区真实产物生成 |
| H2 | T6 前台出现 3 行内部机制话（`计划停在等你回答` / `答复不在该条目的可选范围内 […]` / `检查点已作废`） | 前台面 | 内部判定只进遥测，前台只留**一句人话**承接 |
| H3 | 模型若回一句不接地的话（空话/无问句/不提任何真实产物）则澄清轮没有兜底 | 收口面 | fail-closed：链自身用**同一批真实事实**组装反问 |

## 2. 机制设计（禁关键字/提示词补丁，见 R455 令）

1. **判定面（复用既有分支，不新增规则表）**：`ContinuationBrief.IsContinuationTurn(subTasks)` ——
   仅当意图层判定**没有任务对象**（每条子任务 `WeakIntent`/`TooVague` 且无更具体缺口）时为承接轮。
2. **接地面（事实来自磁盘，零编造）**：承接轮扫描会话工作区（R456 端口根），
   生成 `[承接状态 v1]` 块（产物名/首行/字节数，运行时目录剔除），**只注入本轮 user 内容** ⇒ 静态前缀与缓存不动。
3. **门面（问句接地）**：`EvidenceGate(facts:)` 的澄清问句 = `「{原话}」我没带上下文 —— 工作区里已有: …。你要接着其中哪一项, 还是另有新任务?`；
   无产物时退化为 `… 还没有可接着做的产物。具体要我做什么?`（不得出现任何文件名）。
4. **收口面（fail-closed）**：承接轮回复若"空 / 无问句 / 不含任何真实产物名" ⇒ 链用
   `ComposeFallback(用户原话, 真实事实)` 组装反问；事实为空时只反问、不点任何文件名。
5. **告知面（人话）**：`PlanResumeService.HumanizeVoidNotice` —— 把「答复落不到槽位 ⇒ 检查点作废」
   压成一句：`(插一句: 上一轮你说「继续」我没接上上下文, 问过你要继续什么; 这轮的内容对不上那个问题 —— 先搁下, 下面按你这次的意图办。)`；
   内部术语（`可选范围`/`检查点`/`作废`/`槽位`）**不上前台**，理由仍进遥测。

## 4. 承重不变量（不得破坏）

1. **缓存前缀单调**：`[承接状态 v1]` 只进本轮 user 内容，system/context/history 不变。
2. **零反射/AOT**：只用 `StringBuilder`/LINQ/`Directory`；无 STJ 反射、无动态、无 Regex。
3. **不凭空造事实**：块内每个文件名必须来自扫描结果；事实为空 ⇒ 块与兜底都不得出现文件名（负控单测钉）。
4. **非承接轮不变**：`_continuationFacts == null` ⇒ 门问句、回复路径与 R457 一致。
5. **凭据卫生**：只读工作区文件名/首行（≤40 字符），不读 `.env`/密钥文件（运行时目录剔除）。

## 8. 结果（run2，修正后实跑）

- **A1 产物 4/4 ✅**（count.txt=4 / merged.txt=ALPHA·BETA·GAMMA / stats.txt=chars=14 / first.txt=R455 fixture note；磁盘逐字节）。**A2 ✅** T5 = 「承接一下当前状态：已有 count.txt=4、merged.txt=…、stats.txt=chars=14…「继续」没有指定对象，你想继续做哪件？1/2/3…」（4 项真实事实 + 反问 + 3 选项，示例菜单消失）。**A3 ✅** T6 内部术语 0（一句人话 + 干净答案）。**A4 ✅** 承接块仅 T5 触发 1 次（8 项/共 11 项，state=grounded），收口闸 grounded=true，T5 点名文件全真、零编造。
- **A7 ❌ 未达**：调用 17 > 15。归因 = 模型自身多用工具（`run_command` 3 次做校验、读回核对），非承接机制成本（承接块 1 次 ≈ 288 字符、只进 T5 一轮）；同输入跨轮调用数波动 7→9→15→17，单轮不作趋势结论。
- **预注册外发现（run1，已修 + 机检固化）**：判定只看 flags ⇒ 「当前目录下一共有几个 .py 文件？」（门置信 0.8）被误判为承接轮并注入块，模型把它写进回复；修法 = 与门同判据（flags 弱 **且** 置信 < 0.60）+ 截断如实标注。构建期 `--no-build` 无 `set -e` 造成过一次**假绿**（陈旧二进制 13/13 ⇒ 修后 15/15）。
