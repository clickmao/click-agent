## 诚实边界

1. **结构对齐已机检通过；能力提升未证**。w3 两侧 agent 臂 0/58（A0 `ledger_calls=0` 纯文本作答；A1 8 调用/3 步，产物不可运行，失败面 `life rc=1`）而 codex 同窗 58/58 ⇒ 本轮只宣称「前缀结构 + token 形状对齐」，不得宣称能力增益（铁律 11：w3 `PRECOND_RC=1` ⇒ 该窗作参考/未可验收）。
2. **A0-off（纪律关）行为双峰**：R524 v2 三窗 0/58·0/58·46/58，R525 w3 0 调用 ⇒ 「纪律文本」在本结构下是工具面对齐的**必要条件之一**（A0 臂不构成有效对照臂 ⇒ 本轮对比只取 A1-on × codex）。
3. **M3 在 w1 判否** = 换前缀后的**冷缓存**：cached 5,376 已 ≥ 0.45×system(=4,411 tok)，但**首调用新算 2,582 > 2,000**（未预热段的工具声明+user 题面全算新算）；w2/w3 暖启后新算降到 354/359 ⇒ 判否，w2/w3 判过。**M4 在 w2 判否**（709.5 vs 700）= 边缘波动，不改阈值。
4. **两处后验（post-hoc，须单列）**：① 机检器把「宿主修复回路调用」（system 无 `## §` 段头）从 M1/S* 与步间聚合中剔除（原始判定保留在 `logs/prefix-check.json/.txt`，修正版在 `logs/structure-check-v2.json`）；② S3 段体量上界 4,000 → 12,000 字符，依据取外部真值最大段 10,784，**不是**按本侧读数凑绿。
