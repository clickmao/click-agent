# R587 · 审计器「零产品源码改动对照轮」作用域分支（`tools/roundcheck`）

## 1. 背景 / 动因
R585、R586 两轮的 `tools/roundcheck/roundcheck.py audit` **同形三连红**：

| 判据 | 红的原因 | 结构性? |
|---|---|---|
| `R1_registry_row` | 登记表无 `owner_round=R585/R586` 的行 | 是：这类轮次只做「外部真值 × 产品默认档」对照，**零产品源码改动、零新能力** ⇒ 依「验证登记表缺负控即为门禁真红」的纪律，它**本就不该**有登记行 |
| `R6_commit_hygiene` | 逐窗快照归档 115/124 文件 > 阈值 40 | 是：裸计数阈值本就不表达「是不是 `git add -A` 面」 |
| `R8_readings_backed` | 缺 `build 0 error` / `形式门禁 14/14` | 是：对照轮无构建（零源码改动）⇒ 该读数结构性不存在 |

**两条都不许走**：补一行假登记行、放宽阈值/删断言。正解 = 给这一类轮次一条**可机检的显式作用域声明**。

## 2. 实施（R587，唯一变量 = 该分支 + 其夹具）
- 新声明件契约：`eval/rover/<rid>/audit-scope-<rid>.json`，`audit_scope = {kind, reason, readings[], allowed_faces[], require_form_gate}`。
  - `kind` 必须 == `contrast_zero_product_change`；`reason` 非空（≥20 字符）；`readings` 必须**逐个在位且非空**；`allowed_faces` 不得为空（不接受省略）。
  - 声明件是**独立文件**：触碰冻结预注册 `prereg-<rid>.json`（先写后跑闸所用）被明令禁止。
- `read_audit_scope()` 三条出路：**缺失 ⇒ 返回 None（旧行为逐字节不变）**；**非法 ⇒ 返回 `{ok:False, why}`（出声，不静默豁免）**；合法 ⇒ 生效。
- 生效的三个分支（**仅当**「声明合法 ∧ **提交面零 `src/`**」同时成立）：
  1. `R1` → `PASS(N/A)`：明细里带声明件路径 / kind / reason 前 32 字符；
  2. `R6` → **面形状判据**（提交面每个文件都必须落在声明的面内）**替代裸计数阈值**；垃圾面判据不变；
  3. `R8` → 读**声明的读数面**，要求其中含 `verdict.rc` ∧ `x/y` 通过率 ∧（`require_form_gate=true` 时）`形式门禁` 读数。
- 声明了却**提交触碰 `src/`** ⇒ 分支不适用，回到旧行为判红（这是负控 a）。

## 3. 自证有牙（`--selftest`，正控 1 + 负控 5，全绿）
```
正控: 声明齐 ∧ 提交面零 src/                ⇒ rc=0 (R1 P / R6 P / R8 P)
负控a: 声明了却提交触碰 src/               ⇒ rc=1 (R1 红, 分支不适用)
负控b: 无声明（旧行为）                    ⇒ rc=1 (R1 红)
负控c: 声明非法（读数件缺/为空）           ⇒ rc=1 (R1 红, 明细出声「声明无效」)
负控d: 声明面缺「形式门禁」读数            ⇒ rc=1 (R8 红 —— 豁免 ≠ 什么都免)
负控e: 提交面越界（未声明路径）            ⇒ rc=1 (R6 红 —— 面形状判据, 非裸计数)
还原后                                       ⇒ rc=0
```
夹具构造过程中的**首跑假红**（我的夹具 `allowed_faces` 漏了 `docs/` ⇒ 正控 R6 红）由自检当场抓出：**修夹具/声明的完整性，不放宽判据**。

## 4. 历史判决中性（重审证据，非事后调阈值）
`audit` 的对照轮分支只由「声明件存在」触发 ⇒ 历史轮次（无声明件）走原路径。现盘器具重跑历史轮，判决与登记读数**逐条一致**：

| 轮 | 登记判决（原器具） | 现盘器具重跑 | 一致 |
|---|---|---|---|
| R580 | rc=0（10 条无 FAIL） | rc=0 | ✓ |
| R586 | rc=1（R1 无登记行 / R6 124 文件 > 40 / R8 读数缺档） | rc=1，**同三条** | ✓ |

⇒ 本次器具改版是**纯增量**（历史判决中性）。同时按 R2e 要求，本行所在登记表把 `r582.round-validity-auditor` 的 `instrument_sha12` 重钉到现盘字节并在 `audited_by_round` 记 R587（**重审**，非放宽）。

## 5. 诚实边界
- 本分支**不**证明任何产品质量或成本收益：它只让「对照轮的有效性审计」这件事从**结构性三连红**回到**可判**；对照轮的质量/成本读数仍须由铁律 11 前置器裁决（R587 为 rc=1）。
- `R6` 的面形状判据是「提交面是否落在声明的面内」的**代理**，不是「没有多余文件」的证明 —— 面本身由预注册声明，声明错则判据跟着错。
- `R8` 的 `形式门禁` 要求是本轮**主动保留的牙**（对照轮不构建，但形式门禁仍可跑）；若未来出现连形式门禁也不适用的轮次，应显式声明 `require_form_gate: false` 并留下理由，**不得删除该行**。
- 声明件在 R587 是**跑后**落盘（候选 ⑥ 的器具改动与该轮使用同轮发生），`declared_after_run=true` 已写进声明件；冻结预注册未被触碰。
- 无 CI 接线；本器具只审台账/证据/提交面一致性，不判产品能力。
