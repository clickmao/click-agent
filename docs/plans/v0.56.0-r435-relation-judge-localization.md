## 3. 单变量归因（同一批 9 例，每臂只改一个变量）

| 臂 | prompt | n_predict | 真机 6 例可解析 | 语义正确 | 说明 |
|---|---|---|---|---|---|
| A0 | v0 旧 | 512 | **1/6** | 1/6 | 复现产品 |
| A3 | v0 旧 | 1024 | 2/6 | 1/6 | 仅 turn8 转好，且字母 C≠A（错） |
| A2 | v1 新形态 | 512 | **6/6** | 3/6 | turn3/5/7 判 A（真值 N） |
| A1 | v1 新形态 | 1024 | **6/6** | 3/6 | 与 A2 逐例相同 ⇒ 预算非承重 |
| A4 | v2 新形态+残余带 | 512 | 5/6 | **4/5** | turn9 未闭合 |
| A5 | v2 | 1024 | 5/6 | 4/5 | turn9 在 1024 仍耗尽（67.8s）⇒ 预算证伪 |

**判决**：
1. **承重变量 = prompt 形状**：`1/6 → 6/6`（+833%）。关键两处：① 尾行从裸片段改为**明确 cue**「先思考, 思考结束后必须另起一行只写一个字母 (C 或 A 或 N) … 答案:」；② 把 C/A/N 的**定义与同族实例**写进 prompt（实例**不用 grid 原句**，避免教考同一）。
2. **预算 512→1024 = 证伪**：A1≡A2、A5≡A4 逐例相同；turn5、turn9 在 1024 仍耗尽。⇒ 保持 512（少 35s/例 延迟）。
3. **解析层改动 = 中性（加固）+ 一处撤回**：四臂 old/new 解析结果完全一致 ⇒ 不是承重的；但旧解析在「无任何标记」时搜索**全文**，我自己的器具缺陷已经实证了这条路会从思考链取字母（假阳性 8/9），故保留 **64 字尾窗** + 失败原因可观测，并配负控测试。**判定词表已撤回**：它使既有预注册判据 `RelationJudgeLocalizationTests.J13`（「这是采纳」这类散文**必须未判定**）转红 —— 判官契约 = 结论区必须有**独立字母**，散文兜底是本项目**门**（TurnGateJudge）的语义，不搬到判官；撤表后四条臂读数**逐例不变**（证明零增益），全量测试 1285/1285 绿。撤回动作本身也是一条判据：**新加固不得推翻既有预注册契约**（除非有实测增益背书）。

## 6. 诚实边界

1. **端到端 token KPI 未测**：本轮只到"单组件 + 探针"层；用户令的 ≥30% 必须由新 AOT 二进制重跑 BRJ 网格给出（下轮候选 ①）。
2. **语义残余**：turn7「换个说法。」本地判 A（真值 N）；turn9「从头再说。」思考链无界（512/1024 都耗尽）⇒ 仍回退远端。**6 例里 1 例仍走远端**，故"零远端"未达成。
3. **真值表是我的构造**（预注册于本节与探针 `TRUTH`），非用户确认；turn7 的 A/N 边界属**定义**争议（"换个说法"既非认可也非纠正 ⇒ 判 N），需人工裁定。
4. 解析层/预算两项改动**没有实测增益**（A1≡A2、A5≡A4、old≡new 解析）：前者按"结构性加固 + 负控"保留，后者按"打分不升即回退"**回退到 512**。
5. `kind` 全部为 Neutral（遥测 8/8）：J 通道当前只影响台账奖惩，**不参与是否跳过**的决策（跳过由前置门决定）⇒ 本轮改动对 token 的贡献**仅来自"省掉远端判官调用"**，不是跳过更多轮。
