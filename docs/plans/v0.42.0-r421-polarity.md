# v0.42.0 · R421 计划：跨会话检索的否定极性（`/recall` 假阳性）

**轮次**: R421 · **日期**: 2026-09-14 · **上游**: R420（`/recall` 接线，已 commit）
**靶点来源**: R420 §诚实边界 ③「`hits=0/2` 质量读数暴露词面重叠缺陷（`不存在`→2 命中），已登记为下轮候选，未修」
状态: 已实施（本地 commit 37d6997，**未推** —— 推送暂停令在效）

## 1. 问题（先用真机读数复现，再改代码）

R420 真机：`/recall 外星词根zzq不存在` → **2 命中**。命中原因是 `不存在` 被切成 `不存`+`存在` 两个二元组，而库里两份文档都含 `存在`（断言的是**肯定**命题：`若图中存在拓扑序…`）。⇒ 用户问「X 不存在？」会被答成「X 存在」的证据，**否定被丢掉**。

**根因（词元层，非解析层）**：`Tokenize` 对否定与肯定产出同一词元 `存在`；`Search` 的打分是 `Σ Idf(t)/√|qSet|`，对否定无感。

## 2. 代码事实（改前，行号对齐 R420 产物）

- `src/agent/session/SessionHistorySearch.cs:38-58` `Tokenize`：`Normalize` 后 ASCII/数字词（≥2 字符）+ 相邻 CJK 二元组；**无极性概念**。
- `:73-95` `Search` 打分：`Idf = ln(1 + n/(1+df))`；`score = Σ Idf / √|qSet|`；`:90-93` 整串命中兜底/加成（`qNorm.Length ≥ 4`）。
- `:242-268` `Render`（R420 新增）：`N. <id>  score=…  entries=…` + 片段行；**片段行未换行**（与下一命中行粘连）。
- `src/agent/IndustrialAgentV2.cs:795-835` `/recall` 出口（R420 接线）：本地渲染 + `recall_query` 通道打点，**早返回 ⇒ 零 LLM 调用**。

## 3. 设计（最小改动 + 对称性）

1. **极性问题**：新增 `internal const char NegMark = '\u0001'`。`Normalize` 丢弃全部控制字符 ⇒ 真实文本**不可能**产出该前缀 ⇒ 无碰撞、无需转义协议。
2. **否定标记集 = `不 没 未 无 非`**（5 个）。**有意排除** `别/勿/莫/甭`：`别` 与 `识别/区别/特别` 高频碰撞。
3. **作用域（有界，可陈述）**：当二元组 `(ch, next)` 满足 `IsNegationMark(ch) || IsNegationMark(prev)` 时，该词元加 `NegMark` 前缀。即极性只覆盖「标记本身 → 标记紧邻的 1 个二元组」。
4. **对称性铁律**：查询侧与文档侧走**同一个 `Tokenize`** ⇒ 极性是词元身份的区分（`¬存在` ≠ `存在`），不是查询侧特判 ⇒ 不存在「查询侧改坏召回」的隐式分支。
5. **召回安全**：极性只可能**减少** match（`¬存在` 不匹配 `存在`），不会新增 match ⇒ 假阳性下降；代价是「否定语境下的真阳性」也会漏（见 §6 边界）。
6. **仪器修复**：`Render` 片段行补 `AppendLine()` ⇒ 命中集逐行可寻址（本轮 harness 第一版因此只读到 1/3 命中）。

## 4. 验收（预注册，13 条判据 + 6 单测）

- L4 主判据：治疗臂（新 AOT）`不存在`/`外星词根zzq不存在` 命中 **0**，且 `存在` 仍召回**两个真实正样本**。
- L4 负控：**修复前二进制** `/tmp/pub_r420_pre/agenthost`（R420 产物快照）同 harness、**逐字节相同语料** ⇒ `不存在` 命中 ≥2，且与 `存在` 命中集**逐元素相同**。
- 仪器：两臂语料 sha256 相同且跑后未变；每查询 `recall_query`==1；`llm_call`==0；渲染行可机读。
- 单测：`--filter FullyQualifiedName~SessionHistorySearchTests` 全绿；全量回归不退化；AOT `publish` IL 警告 0。

## 5. 排除项（本轮明确不做）

- 不做句级否定作用域解析（无依存句法，收益不确定）。
- 不做打分的长度归一 / idf 平滑改造（**登记为 R422 候选**，见 evidence §6.4）。
- 不动 `IndustrialAgentV2` 出口、不动通道打点、不新增依赖、不 push。
