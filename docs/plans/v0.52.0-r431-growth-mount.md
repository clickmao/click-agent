## §2 本轮改动（单一变量：growth 挂载 + 挂载可观测）

1. `src/agent.roles/RoleGrowthLedger.cs`：新增只读 `DomainCount`（挂载前置条件可机检；不改任何行为）。
2. `src/agent.modelqueue/LocalGenerationPort.cs`（`TurnGateCounters`）：新增 `LastPromptChars` / `LastRoleSeedChars` /
   `LastGrowthChars` / `LastGrowthDomains` + `RecordPromptShape(...)`；形状取自**实际被发送的那份 prompt**（在 `JudgeTurnAsync` 内构造处记录），不做二次重建。
3. `src/agent.modelqueue/ModelQueueRouter.cs`：`JudgeTurnAsync(..., int growthDomains = 0)` —— prompt 只构造一次并记录形状（可选参数 ⇒ 既有调用零改动）。
4. `src/agent/IndustrialAgentV2.cs`：调用点由 `null` 改为 `GrowthLedger?.RenderForPrompt()`（有界：RenderForPrompt ≤400 再经 BuildPrompt clip 300）；
   `local_turn_gate` 遥测增 `gate_prompt_len` / `growth_chars` / `growth_domains` / `role_seed_chars`；
   一次性 `local_turn_gate_config` 增 `role_growth_domains`（让「挂载是否可能有内容」在链启动即可见）。

**不改**：判据语义（S/P）、机械前置门表、Parse 规则、`MaxTokens=512`、`CacheReuse=false`、槽位 `-np 1`（R429/R430 已钉死）。

## §3 预注册判据（跑测前写定）

| # | 判据 | 期望 |
|---|---|---|
| P1 | 零回归：`growth=null` 路径 BuildPrompt 逐位等于冻结基线 | sha16 == `8749b0a15f102f04` |
| P2 | 挂载可见：growth 非空 ⇒ prompt 含该块且指纹改变 | sha16 ≠ 基线 ∧ 含 `【Role 成长经历】` |
| P3 | 有界（R413 教训：长 prompt ⇒ 判定截断致增益归零） | growth 段 ≤300 字符；prompt 总长 ≤ 355+301 |
| P4 | 可机检：`JudgeTurnAsync` 后计数形状 == 实发 prompt | 挂载臂 growth_chars>0 ∧ 未挂载臂 growth_chars==0 ∧ prompt_chars 两侧各 == 各自 BuildPrompt 长度 |
| P5 | 真机不截断：挂载后门判仍闭合（不得 `thinking_truncated`） | 每轮 `decided=true`，`raw` 末段含结论区 |
| P6 | 真机决策不劣化：挂载臂与非挂载臂同网格决策相同、远端调用/token 不增 | k8r：决策序列逐位相同；远端调用数与 token ≤ 非挂载臂 |

**分母口径（不做新宣称）**：远端调用与 token 取**桩落盘逐请求**（外部真值）；本轮不宣称 token 下降（增益轮 = R424）。
若 P5/P6 失败 ⇒ 结论只能是「挂载会伤判定」⇒ 回退挂载（铁律：打分 < 上版即回退），只保留遥测。

## §4 排除项 / 诚实边界（先写，防事后补）

1. 真机臂 role（`skeptic.rbin`）**growth 域 = 0** ⇒ 真机「挂载效应」只能在**构造 growth 的 fixture role**上测；
   fixture 与真身 role 的差别恰为 growth（profile 逐字节相同）⇒ 单变量成立，但**不是真实用户负载**。
2. 本轮**不测** growth 对判别**准确率**的因果影响（需要带真值标签的「该 S/该 P」题集 + 足够样本），只测**不劣化**与**可见性**。
3. 未测多域、超长 growth 的真实截断行为（单测只证 clip 生效）。
4. 单机单批；非分布。
