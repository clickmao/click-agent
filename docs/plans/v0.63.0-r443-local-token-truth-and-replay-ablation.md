## 0. 承接（R442 的两条边界）
R442 已把口径钉死为三档并列，并给出两个反号发现；但其中**本地 r1 成本全部是「字符/2 折算」**
（R442 诚实边界 #2：M20 真值 ±20% ⇒ 31–35% 带内仍达标、单跳格负号不翻正 = **未验证的断言**）。

代数分解依赖「块序列可加」假设，需要**独立第二通道**（真机单变量）互证。

## 1. 问题

## 2. 设计与约束
- 数据来源：**同一 AOT 二进制** `/tmp/pub_r443/agenthost`，同网格 `M20`（7/20 可跳，信号最强）。
- 代码改动（最小、加性、默认关）：
  - 遥测真值化：`local_turn_gate` / `correction_judge` 各新增 `tokens_evaluated` / `prompt_new` / `gen_tokens`
    （取自 llama-server 上报，非二次重建）；未走 r1 记 `-1`。
  - 反事实开关：`AGENTFRAMEWORK_GATE_REPLAY_SKIPPED=1` ⇒ 本地消化轮的 `SentContent` 回填内联块
    （即 R438 之前的行为）；未设 ⇒ 与生产逐位同形。`local_gate_skip_history` 增 `replay_skipped` 标记。
- 臂：`A-M20`（分母，新二进制）、`BRJ-M20`（默认）、`BRJ-M20-RP`（replay=1）；默认臂复用为 D4 复现对。
- 零 shell / 零反射 / AOT 无 IL 警告；不改默认行为（env 未设 ⇒ 逐位同形）。
