## 2. 本轮已产出的事实性发现（跨 5 项）

1. **头号断链**：框架内**不存在"生成脚本"能力** —— 代码任务只能一段式由 LLM 在回复里吐；不落盘、不执行、不校验、不可迭代（探索项 4）。
2. **"宣称≠实现"再添 3 例**（与 R365 三缺陷同类）：
   - 探索项 3：`OutputCritic` / `CriticPipeline` / `FormatRepairLoop` 已实现但**生产 0 调用**，而 `skills/critic-rules/SKILL.md:82` 声称"输出后机器侧静态扫描复核（双保险）"；
   - 探索项 3：`TaskCharter.AcceptanceCriteria` **0 消费方**（验收标准只声明不校验）；
   - 探索项 4：CLI `(已路由插件)` 文案无对应校验动作（**本轮已删除该空话**）。
3. **前端通知层缺失是共性瓶颈**（探索项 2/5 共用）：`FormatEvent` 有信封零调用、域枚举只有 3 个、`state.snapshot` 不含 lessons、无订阅/游标。
4. **跨步产物不落不传**（探索项 3/4 同根因）：执行器不回传上游产物、步骤产物不持久化、恢复只恢复状态。
5. **bge 全量索引不可行**（探索项 1 实测）：203.5 ms/块、4.9 块/s、RSS 306 MB → 应按需/增量，不做全量自动建索引。
