## 3. 设计

- **单源**：判别通道的唯一开关 = 配置 `local:` 块；模型档位是唯一变量（不新增代码分支、不做档位探测魔法）。
- **内存适配**：3B-Q4 权重 2.10 GiB + f32 KV@4608 ≈ 0.34 GiB ⇒ 常驻 ≈ 2.2–2.5 GiB（本机 MemTotal 3.66 GiB）。`parallel: 1` 承 R430 铁律；`context_size: 4608` 承 K2b「可复用前缀 ≥4224」。
- **失败语义不变**：模型缺失/不可解析 ⇒ `IsAvailable=false` ⇒ 门降级 Pass（fail-open 到远端），行为与关门前逐位一致 ⇒ 采用不可使产品质量退化。
- **前置门保留**：`AGENTFRAMEWORK_GATE_PREFILTER`（默认 on）机械兜住 ¬Ack 轮，3B 只在 Ack 族轮真正决策。

## 4. 约束

- 禁语言/框架特定硬编码；禁关键字补丁（承 R455）；判据面必须锚定产品自身（承 R462-W 铁律）。
- 单变量对照：同网格（R438 `task-p12.json`）/ 同桩 / 同 role / 同二进制，仅 `model_path` 与 `turn_gate` 变。
- 质量硬线：残余带轮（6–9）与纠正轮（10–12）**不得 Skip**；Skip 只在认可族（Ack）生效。

## 5. 验收（判据）

1. **门判走向**：`local_turn_gate` 事件逐轮可读；Ack 族轮 = Skip、其余 = Pass（或 mechanical）。
2. **API token**：同网格同桩下 B3B 相对 A（本地通道关）总 token 下降；B15（1.5B）作单变量对照。
3. **质量不退化**：残余带/纠正轮无 Skip（`quality_risk` 为空）；12/12 轮 ok；回复面非空。
4. **负控**：`BP`（3B 路径不存在）⇒ 门零决策、读数与 A 逐位一致（增益归零）。
5. **形态**：AOT 0 IL + `env -i` 自启 rc=0；构建 0 Error；定向单测通过。
