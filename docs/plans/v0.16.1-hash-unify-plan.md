消费链:
- RAG 运行时: ServiceCollectionExtensions.cs:214 `cfg.EmbeddingFunction = text => new EmbeddingRouter(bgeModel, llmLoaded).Embed(text)` → EmbeddingRouter.cs:126 `CreateBge() ?? new HashEmbeddingProvider()` (llamalocal 256 版, bge 缺失/加载失败时) → RAGConfig.cs:609-618 截断 440ch 后调用。
- 记忆整合: VectorStore (VectorDocument.cs:128 `embeddingProvider ?? new HashEmbeddingProvider(_config.Dimension)`, 384) — DI 注册 ServiceCollectionExtensions.cs:186。
- 两链各自独立向量空间, 互不比。llamalocal 256 版与 vectormemory 384 版维度不同, RAG 降级档 (256) 与 VectorStore (384) 空间分裂。

矛盾: llamalocal 版注释自称 "与 RAG GenerateEmbedding 同款逻辑" — 实为 RAGConfig Tokenize 的残缺复制 (缺 ASCII 标点切/缺中英边界切/缺 2-gram); vectormemory 版自称 "R58 语义" 但仅英文分词 — 中文内容整句 1 桶失效 (R6 曾修同款问题)。

## 设计 (统一到 vectormemory 一份, dim 统一 384)

1. **V1** vectormemory.HashEmbeddingProvider 升级为 RAGConfig.Tokenize 同族最强语义 (无停用词表依赖, 段长 ≥2 保留 + 中文 2-gram 滑窗), 3-seed 摊开桶分配, dim 可配默认 384。调用方全部走 CosineSimilarity (自归一), 实现侧不做预归一化 (与 RAGConfig 内联一致)。
2. **V2** llamalocal.HashEmbeddingProvider 类删除 (EmbeddingRouter.cs:190-215); EmbeddingRouter.cs:126 fallback → `new agent.vectormemory.HashEmbeddingProvider()` (384)。
3. 不动 RAGConfig 内联 (RecallRateTests 锁定其行为; agent.rag 不引用 vectormemory, 扩大引用面超出本轮范围 — 排除项)。

## 关键约束
- 统一语义必须 ≥ 旧 llamalocal 版中文召回能力 (不退化铁律): 保留中文标点切 + 3-seed; 新增 ASCII 标点切/中英边界/2-gram 为升级。
- 维度 256→384: R81 每批清空 data/rag/index.jsonl, 无跨形态持久化向量; 批测 bge 在场 (512) 不受影响。
- AOT 红线: 纯托管无新 native 依赖。
- 双实现删除后 grep `new HashEmbeddingProvider` 全仓仅剩 vectormemory 类定义 + VectorStore 构造 (同 class)。
