## 1. 因果链（为什么是这一步）

R474 首次让**真端点**回话，读到两件事：R 臂 6 轮模板应答 + 3 轮用户可见「模型未产出正文」徽标；产品自记账比供应商 usage 少 21.8% prompt tokens。
R475 修了两处（`IsReplayableReply` 回放守卫 + `llm_call_recover` 补 prompt/缓存字段），但**零真实调用 ∧ 无 llama-server**（MemAvailable 1984MB < 2650MB 闸）⇒ 修复**从未在真机上复演**。
R476 把红线判定分档化并加了 7 个遥测字段，同样只在单测/夹具上验过，**未验实发**。
⇒ R477 = 用同一网格夹具、同一宿主二进制，把「回放守卫」与「分档打点」放到**真端点 + 真本地 r1** 上复演，并复测 KPI 降幅。
