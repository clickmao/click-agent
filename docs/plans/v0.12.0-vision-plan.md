## 0. 事实底座 (真机 + 官方口径, 2026-09-08)

### 0.1 glm-5.3-flash 图像能力 (R2 更正: 有图像理解!)
- **图像理解**: 标准 v4 端点 `https://open.bigmodel.cn/api/paas/v4/chat/completions` (非 coding 子域),
  `content` 多段数组: `{"type":"text"}` + `{"type":"image_url","image_url":{"url": "https://... | data:image/png;base64,..."}}`。
  上下文 1M tokens / 最大输出 128K; 多张图同请求可传; png/jpg/jpeg/webp; thinking 开关可选; 按 token 统一计费。
  ⚠️ 一次请求只能**一类**多模态输入 (图片 OR 文件 OR 视频, 不混)。
- **图像生成: 无**。必须独立模型 `cogview-4` / `glm-image` 走 `/paas/v4/images/generations`。
- 真机已验 (2026-09-08): cogview-3-flash 免费档生成 1024x1024 (8.1s, JPEG 78KB 落盘) ✓;
  glm-5.3-flash 自述不能生图 ✓ (与文档一致)。

### 0.2 两阶段范式 (zcode 方案, 用户钦定)
> 看图+生成新图: ①glm-5.3-flash 理解图片→输出绘图 prompt → ②cogview 生成 → ③glm-5.3-flash 校验 → FAIL 重新生成, PASS 通过。
- 生成器默认照搬 zcode 方案: **理解→生成→校验→失败重生成→通过** 收敛循环。

## 1. Workstream A — 图像理解链 (vision)

1. **VisionChatRequest**: `OpenAIChatMessage.Content` 支持 string | parts[] 双形态 (source-gen DTO 扩展, 向后兼容纯文本)。
2. **图片输入**: 本地文件 → base64 data URL (png/jpg/jpeg/webp; 大小上限待确认, 初定 4MB); URL 直传。
3. **路由**: 意图 `vision_qa` (消息含图片引用时) → 模型选择约束 `capabilities.image_input=true` — 文本模型收图 → 明确报错「该模型不支持图像理解」。
4. **打点**: `vision_call` (kv: model, image_count, image_bytes, ms, ok) + harness summarize init 键同步 (缺陷 58/60 家族教训: 先 quick 批验证)。
5. 端点: 5.3-flash 视觉走 **v4 标准端点** (coding 子域不支持 image_url — 待真机验证一次后写入注释)。

## 2. Workstream B — 图像生成链 (imagegen)

1. **CogViewClient** (已建) 接入 LLM 服务: `capabilities.image_output=true` 路由; size 参数白名单 (1024x1024 等, 官方列表待确认)。
2. **生成-校验收敛循环** (zcode 方案, 默认内置插件 `ImageGenPlugin`):
   - 用户需求 → 5.3-flash 优化为结构化绘图 prompt (风格/构图/元素清单) → CogView 生成 →
     5.3-flash 读图校验清单逐项 PASS/FAIL → FAIL 项反馈重生成 (上限 3 轮) → 全 PASS 交付。
   - 插件接口 `IImageGenPlugin`: Generate(prompt) → path; 校验器 `IImageVerifier`: Verify(path, checklist) → per-item 结果。默认实现内置, 可替换。
3. **打点**: `image_gen_round` (kv: round, checklist_pass_ratio, regenerated) — 收敛曲线进 round-log。
4. 模板 (yaml 可配, skill 目录): 精品像素 (steam 60R 档: 16/32-bit, palette 32-48, 无抗锯齿, sprite 规范) / 原型快出 (速度优先, 校验仅查主体)。

## 3. Workstream C — 无头浏览器插件 (截图供视觉链)

- 契约 `IHeadlessBrowserPlugin`: Open(url, viewport) → ScreenshotPng(width, height)。
- 默认实现: chrome headless (`--headless=new --screenshot`), 用户可替换 (同 imagegen 插件策略)。
- 截图缩放: 宽 ≤1280, jpeg q85 (视觉链上传成本)。
- 待确认: 部署机 chromium 可达性 (RST 名单核查)。

## 4. 图像理解 Skill (skills/vision-check/)

- 触发: 消息含截图/图片路径 + 校验类问题 (「页面左上角有 icon、右侧 table…」)。
- 链: C 工作流截图 → A 视觉链问答/比对 → 结构化报告 (per-item PASS/FAIL + 证据)。
- 打点: `vision_check` (kv: items, pass_ratio, rounds)。
