# v0.99.0 · R515 — 长任务编排器 V1（TaskOrchestrator）

> 目标：让「一个长项目」变成「多次真实执行」。R511 已机检：长任务失败的第一主因不是模型能力，而是**单次动作环步数封顶**（默认 `DefaultMaxSteps=6`、硬顶 32）。本轮把「节点」提升为一次真实执行单元，使**总步数 = 节点数 × 单节点预算**，并把「子任务同步进行」落到可机读的墙钟重叠上。

## 2. 设计

**新增三件（全部零反射 / AOT 安全）：**

1. `src/agent/intent/TaskOrchestrator.cs`
   - `Options{ NodeMaxSteps, MaxNodes, ConcurrentLocalFirst, LocalContextFactory }`；
   - `RunAsync(plan, remote, pollInjections, ct, seedRun)`：远端节点由宿主注入的 `RemoteNodeRunner` 执行（一次真实 agent 轮次），本地节点走 `ILocalNodeExecutor`；
   - `ConcurrentLocalFirst=true` ⇒ 同层本地/远端并发（`plan.MaxParallelism ≥ 2`）；
   - 逐节点墙钟遥测（`Monotonic.NowUs`）：`ElapsedMs`、`OverlapMs`（本地×远端窗口交集）、`BudgetCeiling = Σ 节点预算`；
   - 计划事件 `plan.node`（Running / 终态）经 `IPlanEventSink`，事件出口异常不得打断计划；
   - 检查点复用 `TaskPlanExecutor` 的 `CheckpointStore` 通道（逐批落盘）。

2. `src/agent/intent/TaskPlanFile.cs` — 计划文件（**节点分解的可写形态**）
   - DSL：`id | 依赖(逗号分隔) | 位置(remote|local|hybrid) | 执行器 | 文本`，只切前 4 个 `|`（文本里允许出现 `|`）；
   - `Level` 由依赖深度机算；校验 fail-closed：字段数、id 唯一、依赖存在、成环、local 无执行器、remote 带执行器、空计划；
   - `.json` 走既有 `TaskPlanJsonContext`（同 AOT 上下文，零反射）；
   - `Render` 可回写、`Summary` 可汇报；`Template` 供模型照写。

3. `src/agent.host/OrchestrateCommand.cs` — `--orchestrate <计划文件>`
   - `--node-steps/--max-nodes/--workspace/--session/--report/--upstream-chars`；
   - 节点提示词：只做本节点这一段 + 真实落盘 + 上游产出摘录（默认 2000 字符/节点）+ 计划全貌；
   - 每节点独立审计目录快照 ⇒ **产物归属**（`files[]`）机读；
   - 落盘 `report.json`：`plan_id/run_id/state/workspace/node_steps/budget_ceiling/overlap_ms/nodes[]/node_states`；
   - 退出码：0 全过 / 1 有 Failed / 2 计划非法。

## 3. 约束

- **禁并行铁律不变**：这里的「同步进行」= **子任务编排层并发**（本地子进程 × 远端网络等待的重叠），不是多进程并跑真机测量；同层远端节点的实际并发受模型队列与 2 vCPU / 3.57 GiB 约束。
- 零反射 / STJ 源生成 / 无 `Console.WriteLine`（库内）/ UTF-8 无 BOM / 只用标准库。
- 改链代码 ⇒ **必须重发布 AOT（0 IL 警告）+ 全量单测**。
- 起手闸连续 2 次 PASS 方可起真机臂；每臂独立 session（R509 铁律）；判分只判副本（R512 教训）。

## 5. 排除项（本轮不做）

- 不做「模型自主写计划 → 自动续跑直到 Finished」的 outer driver（本轮节点计划由计划文件给定；`seedRun` 已留跨轮续作入口，未接调度器）。
- 不做审批/澄清注入通道（编排器透传 `pollInjections`，未做端到端实测）。
- 不做预算×规模全曲线（本轮只取单节点 6 步一点 vs 单轮 6 步）。
- 不改既有动作环预算语义、不改既有 `PlanRunner`/`IndustrialAgentV2` 计划面（新件旁挂，默认路径不变）。
