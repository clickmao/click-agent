## 1. 本轮解决什么（用户令：所有候选并入同一轮）

R512 抓到 p4 夹具缺陷（题面未写 `--now` 缺省语义 ⇒ 8/12 条用例依赖题面外约定 ⇒ 两侧同败、判据无区分力），
但**定位靠人工**。候选②要求把它机械化 —— 否则每一轮对照都可能重复踩同一类坑。

候选①（token 判据稳健化）同源：R512/R513 的 token 降幅跨跑次摆动 2 倍级（`849,925–1,266,833`），
用单跑读数宣称降幅不成立。

## 2. 交付物（真机/真语料证据，禁只写文档）

### 2.1 候选② · 题面-判据一致性机检器 `eval/rover/r514/statement_contract_check.py`

| 项 | 事实 |
|---|---|
| 输入 | taskset JSON（`tasks[].{tid,prompt,cases,ref,hidden_cases}`）+ 用例文件（静态 AST，**不执行**被测） |
| 读取面 | `parse_statement` L71（题面选项事实：反引号 + 裸形态 + 取值占位 + 可选/缺省标记）、`parse_cases` L116（用例清单三形态：注册表 / 声明表 / 变换常量；调用点 = 含字面选项 token 的调用）、`check_task` L274（判据装配） |
| 判据 | D1 `case_uses_option_not_in_statement`、D2 `reliance_on_unstated_default`（子分类 binding / masked / spawn_site）、D3 `undeclared_error_token`、D4 `undeclared_json_key`；I1/I2 为信息项（覆盖缺口，不判红） |
| 退出码 | 0 无缺陷 / 1 夹具缺陷 / 2 器具缺陷 fail-closed / 3 缺侧 |
| 词表 | `DEFAULT_MARKERS` L47（声明的读契约；改词表 = 改仪器，必须重跑负控阶梯） |

**核心读数（R512 归档语料，机检）**：p4 题面 v1 → `predicted binding` 集合 = 8 条
（`add_creates_and_lists, id_monotonic_no_reuse, unicode_roundtrip, done_idempotent, done_unknown_id,
persistence_across_processes, no_temp_residue, list_filter_and_order`），与 R512 真机 6 跑次的
**众数失败集合逐字相等**（`eval/rover/r514/evidence/nc-r514.json` 内 `binding_eq_observed=true`）；
另单列 `masked=1`（`bad_request_exit2`）——该用例只断言错误码，缺陷被错误路径掩盖，**故不在此前的人工定位里出现过**。

### 2.3 候选① · 判据稳健化 `eval/rover/r514/check_criteria_r514.py`

- 主判据 = `C1_remote_calls_no_worse`（规则式无常数：逐 (窗口,题) 比值 ≤ 1.0 **且** min < 1.0 —— 后半条防「不更差」被当成「更好」）。
- 次判据 = `C2_token_median`（中位数 + 跑次 `n ≥ 5`；`n<5` 或缺 usage ⇒ **弃权单列**，不判红不判绿）。
- 噪声源**预声明**（`prereg-r514.json.declared_noise_sources`，缺 ⇒ rc=2 fail-closed，禁硬编码）。
- 影子自检 `shadow_selftest_r514.py` **9/9**（含 S7 = A/C 互换必须翻转判决、S5 = 弃权形态、S9 = 缺预声明 fail-closed）。
- **归档回放（口径演示）**：在 R512 report 上跑新判据器 ⇒ `C1 pass (max 0.5714)`；
  `C2 = ABSTAIN_N_BELOW_MIN (n_runs=4 < 5)` ⇒ **R512 的 token 判据在新口径下从「PASS」降为「弃权」**（口径变更，非读数变化）。

## 3. 约束与纪律

- 变异在**临时目录副本**上做；冻结语料零字节改动（收尾 sha 回读核对）。
- 前态锚 = 冻结文件本身（**禁取 `HEAD`**，HEAD 前进会静默失效）。
- 期望值只认**机读字段**（`inject_expect_rc` / `binding_eq_observed`），不靠散文判词。
- 预注册在首跑前落盘（`prereg-r514.json`，含器具与冻结输入 sha256）。
- 推送暂停令在效：只本地 commit。
