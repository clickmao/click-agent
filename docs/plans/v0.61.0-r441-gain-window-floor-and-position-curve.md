## 5. 模型与参数（全部**程序化派生**自存档读数，禁手打）

- **δ（每轮角色块开销）**：同轮 A/B 双臂**各恰 1 次调用**的轮上逐轮求差 ⇒ **77 tok 常数**，44 个观测样本；含多次调用轮会产生 −386..77 的伪离散（已在派生中剔除，剔除理由 = 调用数不等 ⇒ 非同构对比）。逐网格: V1/V2b/V4/V5 = [77]。
- **ρ（跳轮残余远端成本）**：跳轮在 BRJ 臂的实测 G_tokens。V4 = 41/42（跳轮仍发一次「微步骤隔离问询」34+7）；V20/p8/p12/V2b = 0（无调用）。同 sha 二进制下两种行为并存 ⇒ 归因未知（**诚实边界**）。主模型取 ρ=41（保守），括号给 ρ=0。
- **m(t)（被弃内联块质量）**：按位置对存档 A 臂 prompt 里 `[本轮参考上下文]` 块长（字符/2）取中位：t2..t20 = 119/87/79/110/94/133/128/130/157/164/163/173/195/183/185/200/220/223/224。
- **λ（移除项标定）**：m 由字符长度估计，与真实 token 节省存在系统偏差 ⇒ 在**带移除项的存档网格**上反解单一比例 λ：V20 0.766 / p8 0.546 / p12 0.779 ⇒ **λ = 0.766**（中位）。
- 模型式（逐轮）：
  - i ∉ S（未跳）：`B(i) = A(i) + δ`
  - t ∈ S（跳）：`B(t) = ρ`
  - 全轮：`B = Σ B(i) − λ·Σ_{t∈S} m(t)·#{i ∉ S, i > t}`
- **样本内自校验（存档网格）**：V1 0.0% / V2b 1.86% / V4 0.43% / V5 0.59% / V20 0.0% / p8 1.75% / p12 0.20% ⇒ 判据「≤3%」= **OK**（R440 的线性 δ(t) 外推被本模型替换）。

### 8.3 结论
- **收益窗口下界远低于 30%**：单次 realized skip 即转正（1/8 → +13.77%，1/20 末轮 → +3.20%）。「≥30%」需要约 **7/20 可跳比**（中簇 46.19%、晚簇 48.57%），或小任务里 1/4 可跳比（32.24%）。
- **位置效应存在且为正**：同 N=20、同 7/20 可跳比下，散布 45.31% < 中簇 46.19% < 晚簇 48.57%（跨度 3.26pt）⇒ R440 C7「位置效应符号被证伪」应修正为「符号为正、幅度小」。
- **两参数律须收窄**：δ=77 tok 只对**主调用**成立且只对 t≤13 成立；t≥14 存在块膨胀（B 臂内联块携带累积 [已完成] 列表）⇒ 逐轮增量 156/193/270/347/418。块质量 m 不是位置函数而是**会话累积状态函数**，同网格实测后 M20 残差 3.79pt → 1.77pt。

### 8.4 缺陷（器具/模型，非链功能）
1. `predict_r441.py` 的 `a_map_proxy` 未按 N 截断 ⇒ W8 分母取 V4 全长 61281（应 17260）；已修，修正版输出 `predict-r441-postfix.json`（标 POST_HOC），W8 命中 13.18%（ρ=0: 13.42%）vs 实测 13.77%。
2. 跨网格 m 中位 + λ=0.766 标定在长会话上失效 ⇒ 改用 `blockmass_r441.py` 同网格实测。
3. W20 的严格前缀恒等失败根因 = 工作区路径长度进 system prompt（+1 tok/轮），与门/r1 无关。
4. 阶段二脚本把网格当第 4 位置参数（`run_arm.sh` 只吃 3 个位置参数，网格走 `R441_GRID`）⇒ 误跑 W8 一次；已登记为**意外复现对**（降幅 13.77% vs 13.76%，Δ0.011pt）。
