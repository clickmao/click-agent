# v0.12.0 渲染器技术调研报告 (深度调研 — 待人工审批)

> 状态: **调研完成, 等待人工审批** — 审批通过前不进行下一步开发。
> 依据: 用户钦定 (2026-09-08) — 图像生成不调外部 API, 改用本地渲染器 (图形/SVG); 需深度调研后报告。
> 本文为渲染器选型唯一权威源; 批准后据此实施。

## 1. 需求回述

- 图像生成路径: LLM 输出**结构化绘图指令** (SVG/图形描述) → **本地渲染器**离线渲染成 PNG/SVG 文件。
- 部署形态: linux-x64 服务器 (无 GPU), **NativeAOT 发布** (项目铁律)。
- 消费场景: 任务目标可视化 (icon/图表/原型图/像素风资产), 生成后由 glm-5.3-flash 视觉链校验收敛 (zcode 环)。

## 3. 真机验证记录 (2026-09-08, /tmp/svgprobe)

1. ✅ `SkiaSharp 4.148.0` + `SkiaSharp.NativeAssets.Linux 4.148.0` → **程序化画图渲染 PNG 成功** (256x256, 2942B, rect+circle)。
2. ❌ 缺省不带 native → `DllNotFoundException: libSkiaSharp` — **NativeAssets.Linux 包必须显式引用** (关键坑, 已记录)。
3. ❌ `Svg.Skia 5.2.3` 的 `new SKSvg()` 在本机抛 TypeInitialization (SKSvgSettings → System.Drawing 依赖链) — 服务端需额外 shim, 见 §4。
4. 版本坑: Svg.Skia 5.2.3 要求 SkiaSharp ≥4.148 (3.119 会 NU1605 降级错)。
5. 文本 API: 4.x 移除 `canvas.DrawString` → `SKFont` + `DrawText` (文案口径以 4.148 为准)。

## 4. 风险与开放问题

- **R1 (高)**: Svg.Skia 5.2.3 SKSvg ctor 本机崩溃 — 若审批选「SVG 中间表示」需先解决 (候选: 补 System.Drawing shim / 降版本 / 改用 rsvg-convert CLI)。**若审批选「程序化 API 直绘」则完全绕开此风险** (推荐)。
- **R2 (中)**: SkiaSharp native (libSkiaSharp ~10MB + harfbuzz) 与 NativeAOT 的组合未实测 — 批准后第一件事即做 AOT 冒烟验证 (项目铁律)。
- **R3 (低)**: 文本渲染字体: 服务器需至少一款 sans 字体 (fontconfig), 无字体环境文字会缺字 — 渲染器设计已含字体探测降级 (文字转路径/忽略文本)。

## 5. 推荐架构 (若审批通过)

```
LLM (glm-5.3-flash, 文本) 
  → 输出结构化绘图 DSL (JSON: shapes[] {rect/circle/line/text/pixel-grid, 坐标, 色板})
  → RendererService (SkiaSharp 程序化 API 直绘, 512-1024px)
      → PNG 落盘 data/generated/
  → glm-5.3-flash 视觉校验 (已有能力, 真机 ✓) → zcode 收敛环
```

- **为什么不选「LLM 生成 SVG 再渲染」**: LLM 生成 SVG 语法错误率高、坐标漂移大、校验-重生成收敛慢; 结构化 DSL (受限形状词表) 语法可靠性高、可打点 (shape_count/render_ms)、校验断言可逐项绑定 — 符合项目打点/真断言纪律。
- SVG 输出仍保留: DSL → SVG 文本导出为第二产物 (用户要求「可渲染成图形也可以是 svg」), 由同一 DSL 双后端 (Skia raster / SVG text) 输出 — 无需 SVG 解析库, 绕开 §4 R1。

## 6. 分期实施 (审批通过后)

1. **RendererService 骨架** (SkiaSharp 程序化): DSL v0 (rect/circle/line/text/palette) → PNG; AOT 冒烟。
2. **SVG 双后端**: DSL → SVG 文本 (纯字符串模板, 无依赖)。
3. **LLM DSL 生成**: 5.3-flash 按任务目标输出 DSL JSON (schema 校验)。
4. **收敛环接入**: 渲染 PNG → 5.3-flash 视觉校验 → 逐项反馈重生成 (≤3 轮)。
5. **打点**: `render_call` (kv: shapes, ms, ok, file_bytes) + `converge_round` (round, pass_ratio)。
