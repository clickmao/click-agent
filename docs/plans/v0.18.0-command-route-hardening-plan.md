## 1. 设计

### T1 路由一致性静态审计 (单测, 防回归根本)
- 反射/静态读 Known 集合 → 断言每个指令 ∈ (switch 臂 ∪ 显式豁免集)。
- 豁免集**显式化**: `LocalCommandRouter.PreRoutedCommands` = {"/model","/balance","/official-key","/log"} (V2 前置特判, 注释引用) — 测试引用常量而非魔法。
- 测试失败 = 新指令漏臂的编译期前哨 (防 /skills 首版事故复发)。

### T2 fail-closed 硬闸 (V2, 防幻觉假执行主防线)
- V2 指令输入路径: TryRoute 返回 NotCommand **且**输入首词 ∈ Known → 拦截链断裂 → 返回内部错误响应
  "⚠ 本地指令 {cmd} 未完成路由 (内部错误) — 已阻止送 LLM 防假执行; 请报告" + AgentTelemetry.Emit("route_break")
  + ExecutorLessonMemory.Record("route-break:{cmd}") — **绝不落 LLM**。
- 位置: V2 localCommand 处理点 (TryRoute 调用后立刻判)。

### T3 未知 /x 输入的 LLM 假执行输出轻防线 (二期, 低优先)
- / 前缀但不在 Known 的输入落 LLM 属设计 (模型解释"非本 CLI 指令"); 防模型假装执行: 输出后检查回复
  是否含 "执行 .*git|```.*git (status|diff|commit)|输出：" 伪执行模式 → 打点 suspect_fake_exec (不阻断, 观察)。
- 二期实施 (本期只 T1+T2 — 防止范围膨胀; suspect 打点埋点随 T2 顺带)。
