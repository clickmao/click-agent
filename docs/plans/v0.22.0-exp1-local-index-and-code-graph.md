## 2. 实测数据（本轮新增，探针 `/tmp/bge_bench`）

> 用户问「bge 自动建立效果如何？」—— 以下为**本机实测**，非估算。探针复用 `agent.embedcpu` 真实实现，语料 = 本仓 `src/**/*.cs` 切片（480 字符/块，近似 bge 512 上下文）。

| 指标 | 实测值 |
|---|---|
| 冷加载 | `cold_load_ms=0`（**惰性**：构造不加载，首次 Embed 才加载 — 与 §1.4 双检锁一致） |
| 样本 | 300 块，平均 465 字符（来自 296 个 `.cs` 文件） |
| 单块耗时 | **203.54 ms/块** |
| 吞吐 | **4.9 块/s ≈ 2 287 字符/s** |
| 内存 | managed 93.6 MB / **RSS 306.0 MB**（模型常驻） |
| **全仓外推** | 仓库源码+文档 3 061 209 B ≈ **6 375 块 → 约 21.6 分钟**（单线程、不含增量失效重算） |

**仓库规模事实**：`src/` 下 296 个 `.cs`（排除 bin/obj）、`docs/` 78 个 `.md`、`git ls-files` 989 个文件、源码+文档合计 3.06 MB。

**结论（数据说话）**：
- bge **全量**预建索引 ≈ **21.6 分钟（外推）**；进程 **RSS 306 MB**（含模型常驻，**不是索引体积**：512 维 fp32 索引本体 ≈ 12.4 MB）—— 与用户钦定的「本质上不主动探索全量」**正面冲突**。
- 但 bge 的**增量/按需**使用成本可控：单块 203 ms ⇒ 对「已由关键词命中/正在页面显示的 20~50 个片段」做语义重排 ≈ 4~10 秒（后台异步可接受）。

## 3. 候选方案对比（直接回答 I4）

| | **方案 A：纯关键词倒排** | **方案 B：纯 bge 向量索引** | **方案 C：插件返回 graph** | **方案 D：混合分层（推荐）** |
|---|---|---|---|---|
| 覆盖 | 字面匹配（含中文需分词策略） | 语义模糊匹配 | **结构化边**（定义↔引用） | A 打底 + C 补结构 + B 按需语义 |
| 首次成本 | **不需要倒排**：惰性扫描 7.35 ms/查询（§2.6） | **21.6 min / 6 375 块（外推）**，KPI 判定不做 | 取决于插件实现，可按需只算单文件 | A 惰性扫描+缓存、C 补结构、B 按需 |
| 常驻内存 | 小（索引 ≈ 语料字节级） | **306 MB**（实测 RSS） | 边集（可控） | 小 + 模型按需 |
| 失效重算 | 逐文件增量 | 变更块重嵌（203 ms/块） | 单文件重算 | 增量 / 按需 |
| 回答用户问题 | 查找/显示足够 | 「效果」= 语义召回好但**建不起全量** | **唯一能给「谁引用谁」** | A 保底、C 补结构、B 提质 |
| 与「不主动探索全量」 | ✓ 完全一致 | ✗ 直接冲突 | ✓ 按需 | ✓ |
| AOT 约束 | ✓ | ✓（embedcpu 已 AOT 可用） | ✓（显式注册 + 单行 JSON 契约） | ✓ |

**三个否决性判断（基于证据）**：
1. **B 不能做「全量自动建索引」**：21.6 min / 306 MB 与用户钦定前提冲突（§2）。B 只能作为**按需二级重排**。
2. **代码引用索引只能走 C（graph）**：bge 语义向量天然给不出「谁引用了谁」的结构化边；且引用索引的存储/遍历基础完全缺失（§1.6-1）。插件返回强类型边集可**直接复用**已有契约（单行 JSON [src/agent/registry/CapabilityPlugin.cs:37]）与外部脚本范式（task-json + JSON Lines 事件流 [src/agent.skills/ScriptPluginRunner.cs:95-178]）。
3. **图必须有「语言感知」的现实边界**：本仓无 Roslyn（AOT 下 Roslyn 不可用），C# 引用抽取只能走**轻量文本/正则 + 约定**（`Type.Member` 出现点、`using`、`new X(`、`X.Y(`），或由插件（外部脚本/工具）产出。**精度不如编译器**，须在验收里写清「近似图」而非「编译器级精确图」—— 这是**待确认**项（§8-Q3）。

## 4. 推荐设计（分层，全部惰性）

### 4.1 数据模型（落盘，自建头 + 校验）

```
magic "AKIX" (4B) | version u16 | flags u16 | fileFingerprintCount u32 | payloadLen u32
payload = gzip( STJ source-gen JSON )   ← 键名短、字典化、可扩展 "x:" 前缀
```
