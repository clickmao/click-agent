# v0.81.0 · R462 · 召回-现实一致性闸 + 语言无关召回探针

状态: 已实施 (R462)

## 起因 (实发证据, 非推断)

R460/R461 同一夹具 6 轮实跑暴露两条**同源缺陷**:

1. **召回事实被当成本轮真值 ⇒ 编造**：T5 回复宣称 `stats.txt 已写入 chars=15`，而当前工作区**无该文件**（磁盘 0 B，真值 14）。承接块过滤 0 B 文件 ⇒ 模型改用记忆里的旧事实补位。机检 `recall_stale_refs=["stats.txt"]`。
2. **语言无关令未落实 (R447 用户令)**：`ContextAssembler.RecallFromWorkspaceAsync` 用**硬编码后缀白名单** (源码逐字列语言后缀) 过滤候选文件 ⇒ 换语言复用噪声大，正是用户点名要拆的东西。

## 判据 (预注册, 见 `eval/rover/r462/prereg-r462-w.json`)

| 面 | 判据 | 机检方式 |
|---|---|---|
| P1 召回-现实一致性 | 凡含路径样 token 的子句，输出必带 `[核验✓ 现存 N B]` / `[核验✗ …]` | 单测 `RecallRealityGateTests` ×7 |
| P2 外部真值 | 真值取自**当前工作区文件系统**，非模型自判、非提示词改写 | 单测：删除文件 ⇒ ✗；存在 14 B ⇒ `现存 14B` |
| P3 fail-safe | 无 root / 不存在 / 异常 ⇒ 原样返回；越界 (`..`) 不探测 | 单测 `Verify_NoRoot_FailSafe` / `Verify_TraversalToken` |
| P4 幂等 | 已带标签的块二次通过不重复追加 | 单测 `Verify_Idempotent` |
| P5 语言无关 | 闸与召回管道源码内**零**语言后缀字面量 (标签集读 `config/base/language-tags.txt`) | 单测 `*_HasNoLanguageSuffixLiteral` / `*_HasNoSuffixWhitelistLiteral` |

## 设计 (机制, 非关键词补丁)

- 新增 `src/agent/context/RecallRealityGate.cs`：子句切分 (有界 128) → 结构判定路径样 token (零后缀白名单) → 工作区探测 (有界 128；直接相对路径 + 一层子目录同名) → 追加核验标签。异常/越界一律 fail-safe。
- 新增 `src/agent/context/WorkspaceTextProbe.cs`：`IsUsableTextFile` (空文件/NUL/不可打印 >10% ⇒ 二进制) 替代后缀白名单；后缀集只在 `AGENTFRAMEWORK_TEXT_SUFFIX_ALLOWLIST` 显式配置时生效。
- `IndustrialAgentV2.cs:~2702`：记忆块注入 prompt **之前**过闸 (`request.SessionMemoryBlock`)。
- `ContextAssembler.cs:~476`：删硬编码后缀白名单；读文件前过 `IsUsableTextFile`。
- 新增数据文件 `config/base/language-tags.txt`（可配，机检与判定器共用，源码零硬编码）。

## 约束与排除

- 不做：让模型自己判断召回真假 (那是幻觉面)；不改提示词措辞；不加关键词表。
- 闸只让**不一致可见**，不阻止模型编造 —— 编造面由产物收口闸 (R457/R461) 单独负责。
- 有界：子句 ≤128、探测 ≤128、候选 token ≤120 字符。
