## 4. 承重发现

### F1（承重）真实并列对是**同文重复**，不是「难例」

- 词袋分数: [0.140764362763, 0.140764362763]（delta = 0.0）
- **同文检测（新增判据 P1b）**: `seq_identical` = True，位置逐词元差 = 0/335，Jaccard = 1.0，`distinct` = [90, 90]
- 结论: `probe-0914125816-p004` 与 `probe-0914125831-p005` 的检索正文**逐词元相同** ⇒ 并列根因是**内容重复**。
- **推论（止损）**: 对同文文档，**任何**打分族（含语义/位置）都必然给同分 ⇒ R423 登记的「换信号族」对**该对**为伪命题；正确落点在**排序/去重层**（确定性 tie-break / 同文折叠），不在打分公式。

### F2（承重）R423 证据的闭式基线取自**呈现精度**

- 精确等式（机检）: `0.059 × TfSat(4)` = 0.14079136730607356 **==** R423 登记值 0.14079136730607356 ⇒ True
- 全精度应为: score = 0.14076436276343704，其未饱和基数 = 0.05898868348219042（呈现值 0.059 的相对误差 0.00019184218296707526）
- 影响: R423 的**比值**判据不受影响（比值在同源呈现值上部分相消），但「A 臂闭式复算 rel 6.8e-5」应改写为「与**全精度**基线比对」；B 臂读数逐位重现，判定不动。

### F3 位置信号族「非空」但在真实数据上**无判定样本**

- 构造样本（同 `distinct` 计数 ∧ 同 `tf` ∧ 同 `df`，仅查询词位置不同）: ratio = 1.46875 == 闭式 1.46875 ⇒ 位置族**可分且零参数闭式可复算**。
- 真实语料**不存在**非同文的并列对 ⇒ 位置族对真实数据的增益**未证** ⇒ **不实现**（预检判 NOGO 的正当性）。

### F4 新边界（宣称范围上界）

- 构造负控: 同 `distinct` ∧ 同 `tf` ∧ 同 `df` ∧ **同首现相对位置** ⇒ 位置族亦并列（`pos_tied` = True）⇒ 「换到位置族」的宣称上界被精确刻画为**仅能分开查询词位置不同的文档**。
