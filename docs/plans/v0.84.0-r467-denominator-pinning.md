## 1. 因果链（依据先行；结论 = 可证伪假说）

1. R466 把漂移归因为「判官路由（R465 8 次 judge 走远端、R466 同 prompt 走本地）」。**观察正确，归因待证**：
   - 产品代码里产生 `correction_judge.source == "remote"` **且真有远端调用**（`prompt_len > 0`）的唯一路径 =
     `_modelRouter?.RelationJudgeEnabled != true`，而 `RelationJudgeEnabled = _localPort != null && LocalChannel.RelationJudge`
     （`src/agent.modelqueue/ModelQueueRouter.cs:330`；调用点 `src/agent/IndustrialAgentV2.cs:1843`）。
   - 逐条比对两侧 `calls-Arole.jsonl`：R465 有 8 条判官形调用（`n_messages=2` / 系统串 8 字 / prompt≈145 tok），
     R466 同位置 **0 条**（8 次走本地）。两侧 judge 事件总数都是 12，其中 4 条 `prompt_len=0` = **机械短路**（未发请求，≠ 远端调用）。
2. 而臂脚本自身：R465 `run_arm.sh:43` = `Arole) … RJ=false`，R466 `run_arm.sh:39` = `Arole) … RJ=true`。
   ⇒ **假说 H1：13↔21 漂移的真因 = 臂定义漂移（脚本 RJ 标志），不是产品路由不确定性。**
3. 后果（本轮必须修的器具缺陷）：台账里**没有判官路由字段**，「Arole = 稳定分母」这一前提可在两轮之间静默失效而无人察觉；
   任何以 Arole 为分母的 KPI（≥30%）都可能因为一行脚本 flag 而不可比 —— 用户口径明确要求「同题优化前后对比」，分母漂移即该对比不成立。
4. 生产面事实（`config/base/models.yaml` 逐字）：`turn_gate: true` + `relation_judge: true`
   ⇒ **生产等价分母 = R466 的 13/32,097**，R465 的 21/33,323 是「判官未本地化」的历史配置，不是分母。

## 3. 器具（本轮的实交付物）

### 3.1 `eval/rover/r467/settle_r467.py`（在 r466 settle 上增列，不改判据语义）
新增字段（每臂 `arm-<ARM>.json` / `ledger-<ARM>.json`）：
- `calls_class`: 由**桩侧** `calls-<ARM>.jsonl` 逐条分类 `main / judge / micro / other`（分类规则：末条 user 前缀 `判定用户消息相对上一轮回答` ⇒ judge；
  前缀 `[微步骤隔离问询]` ⇒ micro；其余 = main）。外部真值面 = 桩日志，不信被测量自报。
- `judge_route`（由宿主遥测 `correction_judge` 派生）：`events / local / shortcircuit / remote_real / remote_fallback`
  其中 `shortcircuit = source=="remote" ∧ prompt_len==0`（机械短路，零请求）、`remote_real = source=="remote" ∧ prompt_len>0`、
  `remote_fallback = source 前缀 "remote_fallback"`。
- `remote_llm_events`: 宿主遥测 `llm_call` 点数（内部计数），与桩侧 `calls`（外部计数）做**内外一致性**机检。
- `arm_flags`: 从**生成后的 config** 解析（`local.turn_gate` / `local.relation_judge`）+ 脚本写出的 env 声明 + 二进制 sha + role 夹具 sha + 网格名。

### 3.2 `eval/rover/r467/denominator_gate.py`（新闸；fail-closed）
对给定臂台账机检 4 条，任一红 ⇒ 该臂分数**不可比（VOID）**：
- G1 **恒等式**：`calls == len(main) + remote_real + len(micro) + len(other)` 且 `remote_real == judge_route.remote_real`；
- G2 **内外一致**：`calls == remote_llm_events`（桩 vs 宿主遥测）；
- G3 **路由干净**：`relation_judge==true` 的臂 ⇒ `remote_fallback==0 ∧ local>0`；`relation_judge==false` 的臂 ⇒ `local==0 ∧ remote_real>0`
  （即「真走本地」不得含静默远端兜底）；
- G4 **跨轮可比**：同 `arm_class`（生产等价 = gate/role/rj/rs/priority 元组）跨轮台账的 `arm_flags` 必须**逐键同** ⇒ 不同 ⇒ 红，并打印差异键。
- `--negative-control`：① 用**真实历史** R465 `arm-Arole.json`（RJ=false ⇒ 21 调用）对生产等价 baseline ⇒ 必须红；
  ② 对合法 Qon 台账人为破坏恒等式 ⇒ 必须红；③ 对合法台账正常路径 ⇒ 必须绿。三条实测结果入 `gate-selftest.json`。

## 4. 预注册判据（**跑测前**落盘；判据不许事后改写）
