## 2. 设计

### 2.1 题集加硬（M6）
- **对抗用例注入**: `tasks.py` 增 `HARD_INPUTS{族: [stdin,...]}`，`gen_program_task` 把对抗用例**只注入 hidden**（判定只认 hidden）。
  单族对抗用例 < 3 条 ⇒ `RefuseToEmit`（宁可拒绝发题，不发放无区分度的题）。
- **新陷阱族 `pair_closest_abs_sum`**: 两数之和绝对值最小（并列取数值最小）；陷阱=重复元素可复用于不同下标、负数、全零。
- **见证型数学族（判定=独立验证见证，非比对标签）**:
  - `witness_sqrt_mod`: 求 `x` 使 `x²≡a (mod p)`，**多解合法**；
  - `witness_min_counterexample`: 求最小 `n` 使命题 `P(n)` 为假（Mersenne / n²−n+41），判定端自行复核「n 处假 ∧ 所有 n′<n 真」。
  - 生成器侧 `answer` 仅作 oracle 正控用（一个已知合法见证）；判定端 `grade.py` 独立实现验证（不复用生成器路径）。
- **新失败模式 `wrong_witness`**（见证被拒 ≠ 标签不符），进 `KNOWN_MODES`。

### 2.2 KPI 打点
- `scripts/kpi_probe.py`（新）：
  - 数据源双路: `data/probe/probe-*.json` + 遥测 `data/telemetry/host.jsonl`（`point=llm_call` 的 `prompt_tokens`/`completion_tokens`），按 run **墙钟窗口 `[ts - elapsed_s, ts]`** join（`run_probe` 的 `ts` 是**结束**时刻 —— 实施中先写成 `[ts, ts+elapsed]`，导致 token 静默变 None，已修正并固化负控）；
  - 指标: 整题全对率（铁律口径）/ 用例级通过率 / s/题 / tokens(p,c) / tok/题 / tok/通过用例 / 按族 / 失败模式；
  - 产出: 台账 `data/probe/kpi.jsonl`（按 `(solver,taskset_sha,ts)` 去重）+ markdown 对比报告。
- **硬约束(可证伪)**: 缺字段/`total≤0`/`n_tasks≤0` ⇒ error 退出码 2；窗口内无调用 ⇒ `null` 且显式标注（**不是 0**）；未知失败模式键**保留单列**；同 run 不重复记账。

### 2.3 本机 agent.rover 读数
- `agent.rover forward /tmp/models/prover7b-q4km.gguf --tokens 1..64 --budget-mb 1500 --json` + `/usr/bin/time -v`
  ⇒ 预填耗时 / 峰值 RSS（本机 2 vCPU / 3.6 GiB，唯一 Vulkan 设备是 llvmpipe 软件 ICD）。
- 落盘 `data/probe/rover-forward-{1,2,4}tok.json` + **台账 `data/probe/rover_engine_kpi.jsonl`**（tokens/rc/wall/峰值 RSS/user_s）。
- 64-token 档在 `timeout 900` 内**未完成**（诚实记录：本机 CPU + mmap 流式不可交互）⇒ 改以 1/2/4/8 token 档给可完成的读数。

## 3. 约束（沿用铁律）

1. 判定器**只认隐藏用例**；失败必须分类；判定器必须有**反向负控**（含真机形态: 无围栏裸代码 / 尾部 CLI 状态行）。
2. **整题全对才算过**（用例级通过率会放水，`hardcode` 作弊解曾拿 22.2% 用例级通过率）。
3. 生成期**独立双路径验算**，不一致 ⇒ 拒绝发题；数学题见证必须由**判定端独立验证**。
4. 产物真实形态判定（围栏 / 回复区裸代码 / 落盘产物取最长可编译候选）；回复原文必须落盘。
5. 零反射 / AOT 发布形态不变；本轮不动产品链，改动集中在 `eval/probe`、`scripts`、`docs`。
6. 推送暂停令生效（`.git/PUSH_PAUSED`）⇒ 仅本地 commit。
