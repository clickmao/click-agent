## 1. 问题定义（先拆前提）

- **被优化对象**：链管道里本地 r1 的**判官调用**（`CorrectionDetector` → `LocalGenerationPort` 的 `local_turn_gate`/判官通道）。
- **承重读数（R446/R447 已测）**：判官本地成本 = 预填充 2764 + **生成 1974**（M20 全本地真值 7841）；M20「含本地真值」口径降幅 **33.32%**（远端口径 46.18%）。
- **R447 已证死的一条路**：解码侧强制单字母（GBNF）⇒ 取消思考 ⇒ 判决退化为首 token 先验（18/18 恒 `A`）⇒ 等价失败。**思考是判决的承重结构。**
- 故本轮唯一未测的降本形态：**保留思考、限制思考长度**（"思考最多 2 句"，`n_predict` 收敛到 128）。前提 = 必须先证**等价**（与产品原样 prompt 的逐样本判决一致率），否则不得启用。

## 2. 单变量设计

| 臂 | prompt | n_predict | 作用 |
|---|---|---|---|
| J0 | 产品原样（源码派生重建） | 512 | 现网口径基线（**本轮重跑**，不引历史读数当分母） |
| T2 | 产品 + 限长子句 | 512 | 隔离 **prompt 单独效应**（预算与 J0 相同） |
| T1 | 产品 + 限长子句 | 128 | 候选配置 |
| NC1t | T1 同配置 + prev **真错配** | 128 | 非空心负控（8/8 机检真错配） |

- 限长子句（唯一插入文本）：`思考最多 2 句 (不超过 40 字), 不要展开推理。`
- 插入锚点 = `CorrectionDetector.cs:BuildJudgePromptVerbose` 的「先思考…」字面量（**源码派生，禁手打**）。
- 解码档全程钉死：`temperature 0.0 / samplers=["temperature"] / cache_prompt=false / seed 0 / stream false`。

## 4. 预注册判据（`prereg.json` 逐字）

| 判据 | 阈值 | 理由 |
|---|---|---|
| C1 非空心 | 每臂可解析率 ≥0.90；T1 字母种类 ≥2 | 防「恒一字母」伪等价（R447 教训） |
| C2 生成降幅 | `mean(gen|T1) ≤ 64` 且 `比值 ≤0.36` | 参照 R447 冻结读数 178.6（机读取值） |
| C3 prompt 单独效应 | `mean(gen|T2) ≤ 0.75·mean(gen|J0)` 且 `agree(T2,J0) ≥0.90` | 把「限长子句」与「预算」两个因子拆开 |
| **C4 等价** | `agree(T1,J0) ≥0.90` 且 `agree(T1,归档字母) ≥0.90`（12 条遥测 local 真值） | **启用前提** |
| C5 截断闭合 | T1 `thinking_truncated == 0` 且 J0 ≥1 | 闭合 R447 CH3（1/18 触 512 上限未吐字母） |
| C6 负控 | 真错配 8/8 且 `agree(NC1t,T1) ≤0.85` | 证明 T1 判决仍依赖 prev（非空心） |
| C7 记账/形态 | `cache_n≡0`；逐样本 `prompt_n` 跨臂相等；`tokens_evaluated == timings.prompt_n + cache_n`；argv 自证 | 闭合 R447 C5 未测恒等式 + 防形态误读 |

**决策规则**：C1..C7 全绿 ⇒ R449 产品化候选（代码开关默认关 + AOT 重发布 + M20 三臂真机 A/B）；任一红 ⇒ 负结论归档。
