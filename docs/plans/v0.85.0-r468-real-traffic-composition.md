# R468 计划 · 真实流量组成 vs 网格组成：门判降幅的**外部效度**机检

- 轮号: R468（本侧主线轮）
- 状态: 已收口（R468）— 判据落盘早于复现跑；探索性首跑先于本文（见 §7 ①），读数单列 posthoc

- 产物: `eval/rover/r468/{gate_rules.py, real_traffic_classify.py, real-traffic.json, real-traffic-corpus.jsonl, run_tests_x3.sh}`、`src/agent.tests/GateRulesPortDiffTests.cs`、`docs/reports/r468-real-traffic-composition.md`

## 1. 因果链

R465/R466 已把「真诉求轮可跳面」做到默认臂 **−56.40% / −54.73%**（同网格 p12），但该降幅的分母与分子都取自**同一张 12 轮网格**：
- 网格组成 = 4 认可族 + 2 纯复述族 + 6 其他 ⇒ **50% 的可跳面**；
- 该组成是 R438 起为**族覆盖**而设计的（每族各取若干），**从未机检它是否代表真实用户分布**。

R449/R452 曾报「真实流量 ack = 0/1542 ⇒ 可跳面 = 0」，但那是**旧规则**（仅 Ack 单闸）。R463–R467 引入的新规则（Ack 升为主闸、`IsPureRepeat` 直跳、`MechanicalPass` 优先级）**未在真实语料上复验**。

⇒ 本轮把「降幅的外部效度」变成**机检判据**：用**产品自身的判据**（源码派生端口 + 产品差分校验）在真实用户轮语料上复算可跳面，并与网格组成并列落盘。若真实可跳面 ≈ 0，则「≥30% 降幅」只能在**具备可跳结构的语料**上成立，不得宣称覆盖真实分布。

## 2. 方法（单源，禁自造语义）

1. **规则单源**：`eval/rover/r468/gate_rules.py` 从 `LocalGenerationPort.cs` **解析**派生常量/数组（`AckFamilyChars:304`、`RepeatFamilyChars:356`、`RepeatMarkers:359`、`SubstantiveLengthThreshold:458`、`QuestionSignals:461`、`RequestSignals:469`、`CorrectionSignals:477`），并记录源文件 sha256；端口自检的期望值取**产品自身测试** `LocalTurnGateTests.cs` 的 `InlineData`（G31 认可族 13 例 / G35 纯复述族 15 例）。
2. **差分校验**：`src/agent.tests/GateRulesPortDiffTests.cs` 读语料（真实轮 + 网格 p12 + 产品 InlineData），断言端口标签 ≡ 产品 `MechanicalPass|IsPureRepeat|MechanicalAck` 组合标签（同序）。
3. **语料口径**：`~/.hermes/state.db`（只读）`role='user'` 全量 2,585 行；剔除**系统注入**（cron 投递 / 压缩摘要 / OOB / 后台完成通知 / 文档转存）⇒ 真实用户轮；**驱动类**（继续/下轮/下一轮/…，≤30 字）单列 —— 既不计入可跳面，也不当采纳标签（R449 用户令）。
4. **组成对照**：真实语料组成 vs 网格 p12 组成并列 ⇒ 降幅的适用范围。
