## 2. 设计

### 2.1 分词器（新增 `src/agent.rover/token/`，零外部依赖）

1. `ByteUnicode.cs` — GPT-2 字节↔unicode 映射（256 项，与 HF `ByteLevel` 同表：可打印区间保留原字符，其余映射到 `U+0100+`）。
2. `Pretokenizer.cs` — 5 条 Split 正则 + Digits(逐位) 的**预分词流水线**，正则**常量内嵌**并带 `sha256` 自校验
   （规则来自权威 `tokenizer.json`，`sha256` 逐条写进代码：`5cada291…` / `38fd0b5e…` / `ae6bc1cf…` / `16f72e39…` / `a9e31f46…`）——
   自写常量表必须与权威 oracle 对账（沿用 R389 教训：常量抄错会自我印证）。
   Split 语义 = `Isolated`：把匹配段与间隙段**交替切片**（间隙也保留成分片）。
3. `BpeTokenizer.cs` — 从 GGUF 装载 `tokens/merges/token_type`：词表 `token→id`、合并表 `(a,b)→rank`；编码 = 特殊符号优先切分 → 预分词 → 逐片按**最低 rank** 合并 → 帧内缓存；
   解码 = `id→token` → 反字节映射 → **UTF-8 跨 token 拼接缓冲**（多字节字符可能被切成多个 token，必须按字节级累积，不能逐 token 解码）。
4. **显式拒绝而非猜测**: ① 13 个不可映射字节若真出现 ⇒ 抛 `token_byte_unmappable`（不静默替换）；
   ② 未识别的 chat template 构造 ⇒ 抛 `chat_template_unsupported`（不糊一个近似模板）；
   ③ 词表/合并表计数或 sha 与登记不符 ⇒ 拒绝装载（防换了模型还出「看起来能跑」的读数）。

### 2.2 采样器（`src/agent.rover/infer/Sampler.cs`）

- 确定性 PRNG（种子化，同种子逐位可复现）；支持 `greedy` / `temperature` / `top-k` / `top-p` / 重复惩罚。
- 边界语义显式: `temp≤0` 或 `top-p≤0` ⇒ 退化为 argmax；`top-p≥1` ⇒ 全支撑；并列按 id 升序（保证确定性）。
- 采样只吃 logits（不碰前向）⇒ 可单测（固定 logits + 固定种子 ⇒ 期望 id 逐位比对）。

### 2.3 解码环 & CLI

- `cli/GenerateCli.cs` 新增两个子命令（`RoverCli` 分派，`TextWriter` 输出，**禁 `Console.WriteLine`**）:
  - `tokenize <gguf> --text …|--text-file … [--json]` ⇒ ids/tokens/分片，作为编码证据面；
  - `generate <gguf> --prompt …|--prompt-file … [--chat] [--max-tokens N] [--temp T] [--top-k K] [--top-p P] [--seed S] [--ctx N] [--budget-mb N] [--stats-json out.json]`
    ⇒ 一次 prefill + N 次单 token decode（复用 `ForwardPass`，KV 自然累积）→ 解码 → 文本 + 逐步墙钟/`tok/s`/峰值 RSS。
- chat 渲染: 支持 `system/user/assistant` 三类消息 + `add_generation_prompt`（DeepSeek 版式），渲染结果进 `--json` 证据；
  其它构造（工具调用、`continue_final_message` 等）⇒ `chat_template_unsupported`（R403 补齐）。

### 2.4 对账与负控（跨实现铁律）

- **正控**: 199 条夹具（`data/tokref/fixtures.jsonl`，文本→oracle ids，由 HF `tokenizers` 0.23.2 生成）逐条**逐 id 相等**；
- **负控（3 类，必须红）**: ① 字节映射表被换（identity）⇒ 对账失败；② `merges` rank 顺序被打乱 ⇒ 对账失败；③ 关掉预分词（纯字节级 BPE）⇒ 对账失败。
  ⇒ 证明该测试**不是空心**（这三类正是分词器最容易「看起来对」的失效形态）。

## 3. 约束（沿用铁律）

1. 零 shell / 零反射 / AOT 发布形态；新增代码在 `agent.rover`（本工程 `IsAotCompatible`），不改产品链 `src/agent*` ⇒ 不触发 AOT 重发布（`aot_check_policy=release_tag_only`）。
2. 禁 `Console.WriteLine`（走 `TextWriter`）；SIMD 一律 `TensorPrimitives`；跨平台（无 `/bin/sh`、无平台分支硬编码）。
3. 常量表必须带权威 `sha256` 自校验；词表/合并表计数与登记不符 ⇒ 拒绝装载。
4. 读数诚实：本机 2 vCPU + mmap 流式 ⇒ 生成速度预期**不可交互**，读数如实登记（不外推成「可用」）。
5. 推送暂停令生效（`.git/PUSH_PAUSED`）⇒ 仅本地 commit。
