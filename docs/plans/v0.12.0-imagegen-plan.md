## 0. 现状事实 (2026-09-08 真机核实)

- **CogView 生图 API 真机通**: `POST https://open.bigmodel.cn/api/paas/v4/images/generations`
  - `{"model":"cogview-3-flash","prompt":"...","size":"1024x1024"}` → 8.1s 返回 `{"data":[{"url":...}]}` (实测)
  - 下载验证: 1024x1024 JPEG 78KB ✓ (URL 带 watermark 与 Expires 签名, 有效期约 7 天)
- **glm-5.3-flash 不能出图** (真机问询实测: 自述只能文本/SVG) — 用户原始表述「在 glm-5.3-flash 上得到图像」修正为: **通过 CogView 系列实现, glm-5.3-flash 作为 prompt 优化器** (把用户粗需求改写成高质量生图 prompt)。
- cogview-3-flash 免费; cogview-4 付费高质 (价格开工时核实)。

## 1. LLM 服务扩展 (src/agent)

- `ImagesGenerationsClient`: POST images/generations, size 参数化 (1024x1024/768x1344 等, 以官方支持列表为准 — 待确认), 返回 url + 本地落盘 (data/generated/{id}.png)。
- capabilities 矩阵新增 `image_output: true` (CogView 系列 true, 其余 false)。
- 打点: `image_gen` 点位 (kv: model, prompt_chars, size, ms, url_ok, file_bytes) — harness init 键同步。

## 2. 可收敛图像生成 Skill (skills/image-gen/)

### 收敛机制 (核心)
生图质量天然随机 → **生成-评审-迭代循环直到收敛**:
1. 用户需求 → glm-5.3-flash 改写成结构化生图 prompt (风格/构图/色调/元素清单)。
2. CogView 生成 → (计划1 视觉链) GLM-4.5V 按元素清单逐项校验 → 每项 PASS/FAIL。
3. 全 PASS → 交付; 有 FAIL → 失败项反馈进 prompt 重生成 (最多 N 轮, 默认 3)。
4. 收敛判据打点: `image_gen_round` (kv: round, checklist_pass_ratio) — round-log 可见收敛曲线。

### 画像模板 (覆盖工业领域)
- **精品像素游戏 (steam 60R 档)**: 16-bit/32-bit 像素画风, 参考锚定词表 ( Stardew Valley 舒适色调 / Celeste 光影 / Dead Cells 粒子 / Hyper Light Drifter 配色 — 多参考拼接), 限制 palette 数 (32/48 色), 干净像素边缘 (no anti-aliasing), sprite 尺寸规范 (16x16/32x32 tile)。
- **原型快生成**: 简陋像素/几何色块, 优先出图速度 (cogview-3-flash), 弱化细节校验 (checklist 只查主体存在)。
- 模板落在 skill 目录 yaml (风格词/负面词/校验清单可配)。
