## 2. 预注册判据（读数之前写入，不得事后改判；不成立 ⇒ 记 finding，不改判据）
- **C1（r1 路径判别力）**：r1 路径读数中同时出现 ≥1 个 `Pass` 与 ≥1 个 `Skip`（非恒定）。
- **C1p（组合级判别力，C1 不成立时的降级口径，两者都记录）**：机械门产出 ≥1 个 `Pass` 且 r1 产出 ≥1 个 `Skip`
  ⇒ 「机械门 + r1」组合仍有判别力。
- **C2（同文逐位可复现）**：`ack` 族 ×3 与 `cont` 族 ×3 各自 `decision` 恒定 ∧ `raw_len` 恒定 ∧ `raw` 前缀 sha 恒定 ∧ `prompt_sha` 恒定。
- **C3（对齐 + 归因）**：每条门遥测按 **时间窗** 唯一命中一轮（不唯一/未命中 ⇒ fail-closed 不计入判据）；
  `Pass ⇔ 该轮窗口内远端桩调用 ≥1`（外部真值 = 桩侧 jsonl）。
- **C4（隔离负控）**：无任何轮的回复以 `[隔离任务]` 开头；否则该轮作废并按「未测到」记，不得当通过。
- **C5（机械负控位）**：`mechanical_control` 位必须是 `basis=mechanical:*` 且 r1 记录中不得出现该位
  ⇒ 机械门确实不花本地 token 地兜住显式诉求。

### 2.1 判决规则（预注册，读数前写入）
- **PASS** = C1 ∧ C2ack ∧ C2cont ∧ C3 ∧ C4 ∧ C5
- **PARTIAL** = ¬C1 ∧ C1p ∧ C2ack ∧ C2cont ∧ C3 ∧ C4 ∧ C5（残余带内 r1 恒定、判别力只在「机械门 + r1」组合层）
- **FAIL** = ¬C3 ∨ ¬C4 ∨ ¬C5（仪器/旁路/机械负控失效 ⇒ 读数作废）
- **UNDECIDED** = 无任何 r1 读数（未测到 ≠ 通过）
> 判据在 §2 预注册；本 §2.1 只固定**判决合成方式**，同样在读数前写入，避免事后挑选判据。
