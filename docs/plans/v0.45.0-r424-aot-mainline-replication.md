## §1 触发：R413 读数的**发布形态身份不可验证**

R413 台账（`eval/capability/kpi.jsonl` round=R413）记 `agenthost_bytes: 15138848, aot_il_warnings: 0` ⇒ 宣称读数为 **AOT** 读数。
但臂执行器 `eval/rover/r413/run_arm.sh:12` 的被测二进制是：

```
HOST=$ROOT/src/agent.host/bin/Release/net10.0/agenthost
```

本轮实测该路径的事实（三条独立证据）：

| # | 证据 | 读数 |
|---|---|---|
| 1 | `ls -la` | **78,256 B**（同目录并存 `agenthost.dll` 179,712 B）= .NET **apphost 壳**，非原生 |
| 2 | `env -i <bin> --version`（清空环境，无 DOTNET_ROOT） | **「You must install .NET to run this application.」** ⇒ 需要运行时 ⇒ **IL/JIT** |
| 3 | 对照 AOT 产物 `/tmp/pub_r413/agenthost`（15,138,848 B）同命令 | 正常打印 CLI ⇒ 原生自证 |

时序：臂 A `calls-A.jsonl` mtime **10:57**、臂 B `calls-B.jsonl` mtime **12:04:44**；
AOT 发布（`publish_aot.sh -o /tmp/pub_r413`）产物 mtime **12:07:16** ⇒ **AOT 建在测量之后**；
且全仓 grep 无任何 `publish → bin/Release/net10.0/` 的拷贝脚本（该路径唯一写入者 = `dotnet build`）。

**结论（口径红线 #1「AOT 是唯一发布形态；JIT 跑通只算中间证据」）**：
R413 的 12/16,888 vs 8/7,007 **只是 JIT 中间证据**，其 `agenthost_bytes=15138848` 是**事后另做的 AOT 构建**，
不是被测对象的身份 ⇒ 发布形态身份**不可验证**（不断言「一定不是 AOT」——证据不足；断言「未验证」）。

## §7 诚实边界（事后登记）

1. 增益**归因于 r1**：B′（无 r1）增益归零 ⇒ −33.3% 不是机械门的功劳（机械门自身零节省）。
2. **降幅依赖非实质轮占比**：本任务 4/8 = 50% 寒暄 ⇒ −33.3% 调用 / −58.5% token。
   占比为 0 时降幅为 0（例：1/8 寒暄 ⇒ 仅 −8.3%）⇒ 用户令「一轮任务总 token ↓≥30%」在**该任务形态**下达标，
   **不是**任意任务形态的保证；单点读数不能外推为分布。
3. 「回复质量不降」只测到：实质轮回复与臂 A 逐字节相同 + 跳过轮为许可的非 LLM 模板 ⇒ **未做**人类/LLM 评分。
4. `chars/2` 为估算口径（非真 tokenizer），仅比值可用。
5. 逐轮归属对**轮边界上的异步判官调用**存在 ±1 轮滑移（总量精确、未归属 0）⇒ 逐轮表为参考值。
6. 轮 7 在**三臂一致**走「等你回答」本地澄清分支（0 远端调用，回复 168 字）⇒ 非远端实质轮，但同形 ⇒ 不污染差分。
7. 被测二进制含**对端流未提交**的检索侧改动（`git diff --name-only` 证明门/账本/host 模块未改）。
8. n = 1 脚本 × 3 臂，单机单批，非分布；未测并发会话下的门行为。
