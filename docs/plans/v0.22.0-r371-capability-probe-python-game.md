# R371 · 能力差异探针：用 Python 开发一个游戏（宿主 vs 项目 agent）

> 用户钦定口径（R371）：bge 静默后台；**只汇报 5 个开发计划 + 本探针**。
> 方法：同一个游戏任务，① 宿主侧（我）一条链做完并给出可执行证据；② 项目 agent 用 **AOT 发布产物**跑同一任务；
> 逐环节对比（生成 → 落盘 → 校验 → 运行 → 迭代 → 交付），定位断链点并修复。

## 1. 任务（同一提示词）

> 用 Python 写一个贪吃蛇游戏(终端文本渲染)。要求: (1) 单文件 game.py; (2) 核心逻辑与渲染分离,
> 逻辑可用 `python3 game.py --selftest` 无头自测并打印 PASS 或 FAIL; (3) 附运行说明。

## 2. 宿主侧基线（我）

| 环节 | 结果 |
|---|---|
| 写文件 | `game.py`（Snake 纯逻辑 + render + selftest + 交互模式） |
| 真跑自测 | `python3 host_game.py --selftest` → **PASS**, exit=0 |
| 迭代 | 一次通过（无返工） |

结论：宿主能力面 = 「生成 → 落盘 → 真跑 → 读结果 → 修 → 交付」**闭环在一条链内**。

## 3. 项目 agent 实测（AOT 产物 `/tmp/pub_aot_r370/agenthost`，deepseek-flash）

### 3.1 断链点 D1（已修，本轮）：**空正文被判成功**

- 现象：`-q "…贪吃蛇…"` 执行 34.7s，`intent=code_generation`，promptTokens=1395，contextSnippets=9，
  **回复体为空**（stdout 与 `--log` 文件都没有正文）。
- 遥测铁证（`data/telemetry/host.jsonl`）：
  `llm_call: completion_tokens=8192 / content_len=0 / reasoning_len=22633 / success=true`
  `loop_turn: reply_chars=0 / success=true` ← **空回复被判成功**。
- 根因：推理模型（deepseek-flash 返回 `reasoning_content`）把输出预算全花在思维链上 → 正文 0 字符；
  框架只对 **HTTP 异常/超时** 做重试（`OnTransientFailureAsync`），**从不检查正文是否为空**；
  v0.11.0 R19 的旧修只是把 `max_tokens` 2000→8192（抬高天花板，推理照样能吃满）。
- 修复（`src/agent.modelqueue/ModelQueueRouter.cs`）：
  1. 成功路径检测 `content 空 ∧ reasoning 非空` → **有界恢复**：升级预算（8192→32768）+ 追加 system 抑制提示
     （"直接输出最终答案正文, 不要输出思考过程"）重试**一次**；
  2. 恢复成功 → 返回正文并打点 `llm_call_recover(recovered=true)`；
  3. 仍空 → **可见降级文案** + `Success=false` + `Error=empty_content_after_retry`（绝不静默返回空白）；
  4. 成功后 `llm_call` 遥测不再无条件 `success=true`，新增 `empty_reply` / `error_kind`。
- 机检：`src/agent.tests/EmptyContentRecoveryTests.cs` **3/3 通过**（真 HTTP 假端点：恢复路径 / 仍空降级 / 正常不重试零额外成本；
  并断言重试请求体 `max_tokens=32768` 且**新增了一条 system 抑制提示**）。

### 3.2 断链点 D2（待修）：发布产物不自带 config

- 现象：从 `/tmp/gameprobe/work` 运行 AOT 产物 → `失败: 模型目录为空: 请在 config/base/models.yaml 配置至少一个模型`。
- 定位：`ConfigSnapshot.ResolveDefaultConfigRoot()` 已有三级搜索（env `AGENTFRAMEWORK_CONFIG` → cwd 上溯 8 级 →
  程序集基目录上溯 8 级），逻辑本身正确；**真因是 publish 输出目录里没有 `config/`**（发布不自包含）。
- 修复方向（下一轮）：csproj 增加 config → publish 目录的复制规则；并补"发布产物自包含"验收（从任意 cwd 运行成功）。

### 3.3 待观察（本轮重跑）：生成 → 落盘 → 校验 → 运行 链

- `PythonArtifactPlugin`（R368）应把 ```` ```python ```` 段落盘到 `data/artifacts/` 并 `py_compile` 校验；
- L5（R370）新增的运行级验证默认**关**（`AGENTFRAMEWORK_PY_RUN`），需显式开启才能真跑产物；
- 待测：agent 是否 (a) 真的产出完整单文件 game.py，(b) 产物落盘+编译通过，(c) 开启后真跑 `--selftest`，
  (d) **运行结果是否回流给 agent 以便自我迭代**（当前插件只把结果写进报告/遥测，不回流对话 → 预期仍是断链点 D3）。

### 3.4 断链点 D4（已修，本轮）：**裸代码 → 落盘/校验/运行 链全程不触发**

- 现象（D1 修复后复跑）：回复 **9232 字符**、内容是一份**完整优质实现**（`SnakeLogic` 纯逻辑 / `FrameRenderer` /
  `KeyboardInput` / `Game` 组合层 + `--selftest`），但遥测 **零 `script_artifact` 事件**、`data/artifacts/` 无新文件
  → "内置 py 插件"在真机路径上等于不存在。
- 排查（先验伪自己的怀疑）：`ResponseSegmenter` 的围栏正则被怀疑"转义写坏"，用独立 Python 复算 C# 字面量 →
  **正则正确**（真实围栏文本匹配 ✓）。故真因是**回复里没有围栏**：模型裸输出代码。
- 根因：**输出纪律从未要求代码围栏**（`IPromptBuilder.OutputDiscipline` 1–8 条只管长度/问询），
  而机器链（`PythonArtifactPlugin`）**只认 ```<lang> 围栏** → 契约不匹配；且第 7 条"500 字以内"与
  "交付完整单文件"直接冲突，模型只能靠无视纪律才交付得出来。
- 修复：新增第 9 条纪律 —— 交付代码**必须**用 ```<语言> 围栏给出完整文件内容（并显式解除第 7 条字数限制），
  围栏作为机器落盘/编译/运行校验的唯一入口。

### 3.5 断链点 D5（已修，本轮）：运行级验证选参 + 结论上屏

- 问题①：L5 运行级验证**无参**运行产物 → 交互式程序（游戏主循环）必然卡到 20s 超时，
  验证结论退化为"超时"而非"对错"，噪声大。
- 问题②：CLI 只展示"落盘 + py_compile"，**运行级结论不上屏**（用户在终端看不到 exit code）。
- 修复：① 产物内容含 `--selftest` 时自动以 `--selftest` 运行（保守：只认显式出现的串）；
  ② CLI 步骤明细追加 `· run exit=<code> (<ms>)` / `· run 超时(<ms>)`（未开启运行验证时不显示，不假装验证过）。
- 机检：`PythonRunVerifierTests` 新增 2 项（用**退出码 7 vs 3** 证明参数真的传了/没传），族内 **20/20 通过**。

## D4-b v2 (真机 RUN3 驱动): 字符串字面量感知 + 机制归因 (R372)

**真机反例**: D4-b v1 上线后 3 连跑 → 产物命中 **2/3**。未命中的 RUN3 拆开来是两件事:

| 现象 | 遥测铁证 | 定性 |
|---|---|---|
| 正文被输出预算**截断**却判成功 | `llm_call: completion_tokens=8192, content_len=1209, success=True`,正文停在 `start_len: int =` **半行** | **D7 新断链**: D1 的姊妹病 (D1=空正文, D7=半正文) |
| 优质 Python 被判"散文过多"放弃提升 | RUN3 正文带**中文 docstring**(设计要点/用法::/缩进示例);v1 的 35% 散文闸门把串内行当散文 → 拒绝 | D4-b v1 缺陷 |

**修复①(分段器)**: 三引号状态机 —— **字符串字面量内部的行不是散文**(""" / ''' 开关,串内行记中性、并强制 `code=false`),
使"文档健全的实现"不再被自身 docstring 拖累;同时新增归因字段 `ResponseSegment.Promoted`(围栏段=false / 启发式段=true),
`script_artifact` 遥测增加 `origin` 字段 → 产物**来路可归因**(下一轮 KPI 能把命中率拆成 fenced / heuristic)。

**修复②(模型路由)**: D7 截断检测 + 有界续写
- 检测: `LooksTruncated` 纯语法判据 —— 尾部为 `= ( [ { , : + - * / \` 之一、或三引号/围栏未闭合;中文全角句号结尾不误报 (10 例机检)
- 续写: 升预算 (`MaxTokensEscalated`) + 断点提示(尾部 40 字符)→ **恰好一次**;`MergeContinuation` 去重重拼
  (重叠 >=6 字符且含非空白才算证据;纯空白重叠不删,避免吃掉真实缩进);续写返回空 → 保留原文并如实标记
- 始终落遥测: `llm_reply_truncated` / `llm_call_continue`(before/added/after/still_truncated/recovered)

**机检**: `UnfencedCodeDetectionTests` **9/9**(含真 `py_compile` + RED 控制 3 红);
`TruncatedReplyRecoveryTests` **15/15**(真 HTTP 假端点:截断→续写→去重重拼、完整正文 1 次命中零额外成本、续写空→保留原文)。


### R372 真机 A/B 结果（3 连跑, 同一提示词, `AGENTFRAMEWORK_PY_RUN=1`）

| 轮 | 产物 | 字节 | compile_valid | run exit | origin(归因) | 说明 |
|---|---|---|---|---|---|---|
| 1 | py_db1a4ae6 | 14129 | ✅ | 0 | **fenced** | 完整可用 |
| 2 | py_965aa97e | 7633 | ❌ | 1 | **fenced** | **截断**(8192 预算) → D7 检出并续写一次 |
| 3 | py_66885953 | 14388 | ✅ | 0 | **fenced** | 完整可用 |

- **命中率**: 1/3 (D4 提示词级) → 2/3 (D4-b v1) → **3/3 (R372)**;但**有效产物 2/3** (RUN2 截断)。
- **归因反转(关键诚实点)**: 3/3 全部 `origin=fenced` —— 本轮命中率提升**来自模型给了围栏**(D4 提示词纪律), **不是** D4-b 启发式;
  若无 `origin` 字段会**误把功劳记在启发式上**。启发式提升本轮 0 次触发(其价值由 L2/RED 机检与 v2 反例修复背书)。
- **D7 真机首次触发(完整证据链)**: `llm_call: completion_tokens=8192, content_len=7510, truncated=true, reasoning_len=20159`
  → `llm_call_continue: before=2735 → added=4775 → after=7510, still_truncated=true, recovered=false`
  → `script_artifact: compile_valid=false, exit=1`(**如实入库, 未隐藏**)。
- **根因假说(下轮验证)**: `reasoning_len` 与正文**共享**同一输出预算 —— RUN2 推理 20159 字符, 正文仅剩 2735 字符起步;
  与 D1(空正文那次的 `reasoning_len=22633 / content=0`)**同源**。若成立, 正解是**首轮按任务类型给足预算**(而非事后续写),
  续写仅作兜底 —— 这同时省 tokens(2 次调用 → 1 次)与轮数。
