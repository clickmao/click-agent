状态: 已收口（R465）— 读数与判据结算见 §8

## 1. 因果链（为什么做这一轮）

R464 已收口：门开臂远端 token −38.52%（Arole 21 调用 / 33,323 tok → B3B 8 调用 / 20,487 tok），
但门控轮墙钟 +40~102 s 每条（本地 3B 生成"，构成本轮三个真问题）：

1. **可跳面只覆盖「认可族（Ack）」**：p12 网格 12 轮里，`再讲一遍。`（t6）与 `从头再说。`（t9）是
   「把上一条答复原样重来」的**真诉求**却仍走远端主调用（各 ≈2.4–3.0k tok）——这是纯粹的
   「不必要的 LLM API 请求」。
2. **本地 3B 的调用代价全部落在用户可见路径上**：Ack 轮 skip 后，答复由本地 r1 生成
   （实测 4 次 × (342 eval + 2 gen) tok，墙钟 40.7 / 40.9 / 70.8 / 102.2 s），权重装载与
   服务拉起也在这一路径里。
3. **`FileLock` 释放路径存在 unlink 竞态**：`Release()` 在「关 fd 后按 pid 校验删锁文件」，
   窗口内下一个竞争者已拿到**同一 inode** 的 flock，而删除后第三方拿到**新 inode** 的新锁
   ⇒ 两个持有者同时进临界区。历史观测：`ExecutorHardeningTests.FileLock_ConcurrentAppend_NoLoss_NoInterleave`
   满载 120 段得 119（丢一次读改写）。

## 3. 设计（本轮实现）

- **D1 纯复述族（真诉求轮可跳面）**
  - 新增 `TurnGateJudge.IsPureRepeat(string?)`：① 归一化（去标点/空白/符号）后含**完整复述标记**
    （`RepeatMarkers`，如 `再讲一遍`/`从头再说`/`重复一遍`）；② 归一化后 ≤14 字且**每个字符都属
    白名单字符集** `RepeatFamilyChars`（任何内容字 ⇒ false）；③ 无问号。
  - 前置门新增分支（**在 `MechanicalPass` 之后**）：命中 ⇒ `Skip` + basis `mechanical:repeat→local`，
    **零 r1、零远端调用**。开关 `AGENTFRAMEWORK_GATE_REPEAT_SKIP`（默认 `on`；置 `off` = R464 行为，供单变量对照）。
  - 本地消化 = **回放上一条答复原文**（`GetConversationHistoryAsync` 取最近一条非空 Assistant 正文）；
    取不到 ⇒ 退回既有兜底串（仍零远端调用）。遥测 `local_gate_skip_reply{kind=repeat_verbatim|repeat_no_prev|template}`。
  - 后置否决条件同步加 `∧ ¬IsPureRepeat`（否则新族会被当不变量破坏而翻 Pass ⇒ 功能静默失效）。
- **D2 本地通道预热**：`ILocalGenerationPort.WarmupAsync`（默认实现，测试桩零改动）+ 宿主启动时
  按 `AGENTFRAMEWORK_LOCAL_WARMUP=1` 调用 ⇒ 把权重装载移出用户可见的门控轮路径；遥测 `local_channel_warmup{ok,ms}`。
- **D3 锁纪律真修**：`Release()` **不再 unlink 锁文件**（锁身份 = inode，存在性 ≠ 是否被持有）；
  `TryBreakStaleLock` 改为只读探测 `IsHolderDead`（死持有者的锁由内核自动放行）；
  `OccupantDetector.Describe` 优先 `/proc/locks` 的活持有者，锁文件内容过期时报「无持有者（上次持有者已退出）」。
- **D4 嵌入通道同形接线（候选⑥）**：`ServiceCollectionExtensions` 的 bge 注册改用
  `LocalChannelWiring.ResolveEmbedder(declared, envPath, DefaultModelPath)`；声明缺失 ⇒ 告警可见 + 仍返回空实现（fail-open 但可见）。
- **D5 器具与结算**：`eval/rover/r465/{run_arm.sh, run_all.sh, settle_r465.py}`；外部真值 = 桩侧 `calls-$ARM.jsonl`；
  另加 llama-server pid 采样（`server-$ARM.txt`）作「常驻性」外部证据。

- 不把 Ack 轮本地答复生成改为模板串（会改变默认面回复质量语义；留作候选）。
- 不调 llama-server 参数（`-b/-t`）做延迟博弈；不引入前缀缓存（R429 钉死）。
- 不改远端供应商/模型；不做真实计费面替换（候选④，见 §9）。
- 不动 bge 的向量语义与召回口径。
